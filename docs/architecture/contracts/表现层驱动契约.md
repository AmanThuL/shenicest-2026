# 契约：表现层驱动

> gameplay 程序（交互层组件，如 `HelmetController` / `ToolUseController` / `InvestigatableTarget`）↔ 技术美术之间的唯一接线方式。
> 上层规则：[运行时架构](../运行时架构说明书.md)（D1：表现层绝不回写真相层）。
> 状态：接口已在代码中落地 · 最后修订 2026-08-24

---

## D17 —— gameplay 程序驱动表现的唯一通道

**gameplay 程序绝不直接设 material / shader 参数。** 持有 View 引用的交互层组件只调下面这组接口，技术美术在实现里接 Animator / Shader Graph / VFX。

```csharp
public interface IInteractableView { void SetFocused(bool on); void SetInvestigated(bool done); }
public interface IZoneView         { void SetZoneProgress(float t01); }   // 0 = 污染区, 1 = 异色草带
public interface IHelmetView       { void PlayRemove(); event Action RemoveFinished; }
public interface IToolView         { void PlayUse();    event Action UseFinished; }
```

约定：

- gameplay 程序只调这些方法，**不关心内部是动画、shader 还是 VFX**；
- 技术美术可以先交空实现（打日志），gameplay 程序链立刻能跑通全流程，美术后补——这就是"允许并行开发"；
- `RemoveFinished` / `UseFinished` 是表现层唯一允许触发的事件，且只被持有该 View 引用的交互层组件（`HelmetController` / `ToolUseController`）订阅——演出播完，由订阅方把它翻译成命令入队，才推进真相层状态。这跟 [运行时架构 D3.2](../运行时架构说明书.md#d32--会发命令的-ui-只-raise-频道不-enqueue-命令) 的"UI 只 raise 频道，由 gameplay 侧监听器翻译成命令"是同一个模式，不是表现层直接改状态。除此之外表现层不订阅、不调用交互层或真相层的任何方法——`IWorldStateReader` 只暴露只读方法，表现层在类型上就拿不到能写真相层的引用。

字段留空即可跑通：`InvestigatableTarget` 和 `HelmetController` 上的 View 字段为空时，流程立即完成而不等演出。

## D18 —— 高亮 / 光点

**不要用 `MaterialPropertyBlock`。** 在 URP 下给 renderer 挂 MPB 会把该物体踢出 SRP Batcher，多一个 draw call；本仓 [`guidelines/07`](../../guidelines/07-rendering-urp.md) 第 9 条已经禁用它。

**切片 00 定案：每个可交互物挂一个「光点」子物体（小 VFX 或自发光 quad），`SetFocused` 就是 `SetActive`。**
零管线改动、零批处理影响、美术完全可控，且正对策划案里的「光点引导」。

描边（outline renderer feature）是**管线级**决定，影响所有场景和性能预算——留到 P1，由技术美术决定要不要上。
若将来确实要改单物体外观，走 Material Variants 或 `renderer.material` 实例（同 shader、同 `UnityPerMaterial` 布局时 SRP Batcher 仍能批），而不是 MPB。

> ⚠️ 待策划拍板：策划案里「全程使用光点引导」与「尽量避免过多游戏化图标」存在张力。这个视觉方案定不下来，交互反馈就做不完整——它同时是玩法引导（策划）、渲染（技术美术）和交互反馈（gameplay 程序）的交叉点，最容易一拖再拖。

## D20 —— 音频

音频不给 gameplay 程序发接口，走同一套事件通道：`AudioCueSO` 订阅频道资产（`FlagRaised` 与交互事件）。所有 `AudioSource` 路由到唯一的 `AudioMixer`（[`guidelines/09`](../../guidelines/09-packages-systems.md) 第 13 条）。

脚步声与地面材质关联留到 P1。
