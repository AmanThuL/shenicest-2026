# 废墟风化的三层分工

温室由重复模块拼成，同一套贴图要用在 7 面墙上；但真实的废墟里，
每一面墙的破败程度取决于它站在哪里——朝外的淋雨、穹顶下的干燥、
靠地面的溅泥、屋檐下方的长条水痕。这两件事必须分开做，
否则要么每个实例单独一套贴图（显存爆炸），要么所有墙一模一样（假）。

分工原则一句话：**图案属于模块，用量属于位置。**

## 三层

| 层 | 内容 | 做在哪 | 为什么在那 |
|---|---|---|---|
| 1 部件自身 | 边缘锈、凹槽积污、整体氧化、金属粗糙度、重力流痕的**图案** | Substance Painter，每类模块一套，多个实例共用 | 只跟这块铁自己的形状有关，与它摆在哪无关 |
| 2 位置驱动 | 淋雨面 / 背雨面、水痕的**强度**、离地高度、穹顶遮蔽、朝向 | Unity 着色器，由世界坐标 + 世界法线 + 顶点色驱动 | 世界空间求值，相邻模块在接缝处自动连续 |
| 3 手工独一份 | 塌角、破天沟下的大片锈瀑、积水处的苔毯 | 贴花 decal 或逐实例顶点色 | 叙事重点，不交给程序 |

第 2 层为什么不能做进 UV 贴图：相邻两面墙各有各的展开，
任何在 UV 里画的水痕都会在模块边界戛然而止。世界空间的叠加不知道
模块边界的存在，水痕自然跨过接缝。

## 第 2 层的输入

| 输入 | 怎么来 | 驱动什么 |
|---|---|---|
| 天空遮蔽 | 在**拼装好的整栋建筑**上烘，只采上半球，存进顶点色 | 淋雨量：穹顶下接近 0，外立面接近 1 |
| 世界法线 · 上 | 着色器现算 | 积水、苔藓、落尘 |
| 世界高度 | 着色器现算 | 0–1.5 m 溅泥带；高处更干净 |
| 下方出挑 | 天空遮蔽的梯度 | 水痕的起点 |

天空遮蔽不能进模块的 UV 贴图（它依赖位置），所以烘成顶点色：
每个实例一份、几乎不占显存、着色器直接读。

## 大面积表面：平铺而不是唯一烘焙

模块贴图是「一个模块一套唯一展开」，这对几米见方的构件合适，
对几十米的面就不合适了：温室台基 44.5 m 见方，一张 2K 唯一展开只有
约 46 px/m，脚下必糊。

这类面改成平铺：在一块 4 m 的方形基准面上做材质，2K 就是 512 px/m，
再用世界空间三平面投影铺开。世界空间还顺带保证它跨过台基与楼梯的接缝时连续。

平铺材质的遮罩必须全部用 procedural：平面烘出来的 AO 和曲率是均匀的，
读它们的 smart mask 会退化成整面覆盖。同样地，带方向性的 procedural
（drip、leak 一类）描述的是墙，不该出现在地面上。

判据：单个物件的最长边超过约 10 m，就用平铺。

## 玻璃破损

破损不是每片独立掷骰子——碎裂从撞击点扩散，已碎的邻居越多，
自己越可能碎。这属于**摆放**问题而不是贴图问题，
时机是重建玻璃面片的那一步（原始玻璃面已被删除）：

1. 按暴露度加权选若干撞击种子（近楼梯的低窗、穹顶顶面）
2. 从种子向外扩散，概率随距离衰减、随已碎邻居数上升
3. 每片落在四个状态之一：完整 / 裂纹 / 碎裂残留 / 缺失
4. 前三种是三套材质，第四种直接删面

## 落地顺序

1. 第 1 层：逐模块跑贴图管线（进行中）
2. 拼装整栋 → 烘天空遮蔽到顶点色
3. 第 2 层：Unity 着色器叠加，读顶点色 + 世界坐标
4. 玻璃面片重建 + 扩散式破损
5. 第 3 层：贴花补叙事重点
