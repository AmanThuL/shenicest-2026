```
│   ├── SceneLoader.cs / BootstrapLoader.cs / ScenePaths.cs

├── Events/                   VoidEventChannelSO / GenericEventChannelSO<T> / StringEventChannelSO
│                             / LevelEventChannelSO / ReportEntryEventChannelSO
├── Data/                     LevelSO / PlayerConfigSO / InteractionConfigSO

│                             / PlayerTriggerProbe / HelmetController / IHelmetView

├── Investigation/            InvestigatableTarget / InvestigationService
│                             / InvestigationTargetSO / InvestigationKind
├── Narrative/                RadioSequencePlayer / RadioSequenceSO / RadioLine
└── UI/                       SubtitlePresenter / InteractionPromptPresenter / ReportToastPresenter

Assets/RootsDance/Tests/EditMode/Core/  WorldStateTests / CommandQueueTests
```

**与实施计划的一处偏差**：定案 §2 写的 `SampleTargetSO` + `SpeciesSO` 合并成了一个 `InvestigationTargetSO`（用 `Kind` 字段区分采样 / 识别）。两者在切片 00 的字段完全相同，拆成两个类是无收益的重复（`guidelines/03` 第 15 条）。等识别真的需要"数据库匹配度""近似种"这类物种独有字段时再拆。

**一次采集的完整链路**：

```
玩家按交互键
  → InteractionRaycaster（Update；先查 ToolUseController.IsBusy，一帧只放行一次）
  → InvestigatableTarget.Interact
  → ToolUseController.TryUse(IToolView)   ← 美术的采样演出；未接时立即完成
  → InvestigationService.Submit
  → WorldAccess.Enqueue(AddReportEntryCommand + RaiseFlagCommand)
  → GameBootstrap.LateUpdate → CommandQueue.Drain → WorldState 变化
  → WorldState 事件 → GameBootstrap 算好计数，泵到 ReportUpdated 频道
  → ReportToastPresenter 弹出「官方探索报告已更新 / 土壤样本：01」
```

注意最后这一段：**没有任何组件直接改 WorldState**，也没有任何表现组件反向调用 gameplay。这就是[运行时架构](../运行时架构说明书.md) D1/D7 的全部内容。

## 2. Project Settings：先建 Layer

*Edit > Project Settings > Tags and Layers*，新建四个 layer：

| Layer | 用途 |
|---|---|
| `Ground` | 可行走地面（`PlayerConfigSO.GroundLayers` 勾它） |
| `Interactable` | 可交互物的碰撞体（`InteractionConfigSO.InteractableLayers` 只勾它） |
| `TriggerVolume` | 所有 `TriggerVolume` / `ZoneProgressVolume` |
| `PlayerProbe` | 玩家身上的触发探针 |

然后 *Physics > Layer Collision Matrix*：**`PlayerProbe` 只与 `TriggerVolume` 勾选，其余全部取消**。这样探针不会干扰角色移动，也不会误撞场景。

| 资产名 | 类型 | 谁发 | 谁收 |
|---|---|---|---|

| `ReportUpdated` | Report Update Event Channel | GameBootstrap | ReportToastPresenter |

| `Notice` | String Event Channel | InvestigationService、HelmetController | SubtitlePresenter |
| `InvestigationResult` | String Event Channel | InvestigationService | SubtitlePresenter（正式版应换成独立结果面板） |

### 3.2 配置 → `Data/Config/`

`PlayerConfig`、`InteractionConfig`。默认值已经是可用起点；`PlayerConfig.GroundLayers` 改成只勾 `Ground`，`InteractionConfig.InteractableLayers` 只勾 `Interactable`。

### 3.3 关卡 → `Data/Levels/`

`Level00`（LevelSO），Scene Paths **按顺序**填：

```
Assets/RootsDance/Scenes/Levels/Level00/Level00_Environment.unity

```

第一条会成为 active scene（灯光/环境设置的归属），顺序不能反。

## 4. 玩家 prefab（`Prefabs/Characters/Player.prefab`）

**粗体**是 GameObject，括号写明它挂在哪个物体上；其余行是组件，紧跟在自己所属的 GameObject 行后面。`—` 表示没有需要单独设的字段。

| GameObject / 组件 | 字段 / 备注 |
|---|---|
| **Player**（根物体） | layer: Default |
| CharacterController | Height 1.8, Radius 0.3, Step Offset 0.3, Center (0, 0.9, 0) |
| PlayerInputReader | — |
| FirstPersonController | Config = PlayerConfig |
| PlayerLook | Head = Head, Config = PlayerConfig |
| ToolUseController | — |
| InvestigationService | Result / Monologue / Notice = 对应频道 |
| HelmetController | FlagRaised = FlagRaised, Notice = Notice, Input = PlayerInputReader |
| **Head**（Player 的子物体） | localPosition (0, 1.65, 0) |
| InteractionRaycaster（挂在 Head 上） | RayOrigin = Head, Config = InteractionConfig, Input / ToolUse = Player 上的组件, PromptChanged = InteractionPrompt |
| **TriggerProbe**（Player 的子物体） | layer: PlayerProbe |
| CapsuleCollider | 比 CharacterController 略小，isTrigger 关闭 |
| Rigidbody | Awake 里会被强制设为 isKinematic，不要手动改回去 |
| PlayerTriggerProbe | — |

⚠️ `Rigidbody` 只能在 `TriggerProbe` **子物体**上，绝不能和 `CharacterController` 同一物体（`guidelines/09` 第 9 条）。

## 7. 跑通自测（对应验收标准「不需要通过编辑器手动推进」）

1. 打开 `Level00_Environment`，右键 `Level00_Gameplay` → *Open Scene Additive*，把 Environment 设为 active scene。
2. 按 Play。`BootstrapLoader` 会自动附加 `Bootstrap.unity`，`GameBootstrap` 进入 adopt 模式。
3. 逐条核对：
   - [ ] 能走动、能转视角，不穿地、能上小台阶
   - [ ] 走出起始区 → `flow.left_start_area`（暂无表现，Console 无报错即可）
   - [ ] 进入无线电触发体 → 四行台词依次出现后消失
   - [ ] 进入摘头盔触发体 → 出现「可解除环境隔离」→ 按交互键 → 提示消失
   - [ ] 看向土壤 → 出现「采样」→ 按交互键 → 结果文本 → 侧边弹出「土壤样本：01」
   - [ ] 看向异色草 → 「识别」→ 结果 + 两句内心独白 → 「已确认物种：01」
   - [ ] 同一对象再看一次，提示消失、不能重复采样
   - [ ] 反复进出触发体，无线电不会重播

跑 EditMode 测试：**Window > General > Test Runner** → EditMode 标签 → Run All（跨平台，不依赖 Editor 安装路径）。命令行方式（macOS / Windows 两条命令、Editor 路径怎么替换）见 [`guidelines/08`](../../guidelines/08-testing-tooling.md#running-tests)。
