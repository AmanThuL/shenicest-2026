# 旧档案：拾取与阅读

> **目标**：让玩家能从场景里**拿起一张落灰的旧纸**，举到眼前，**擦掉灰**、**推近拉远**、**转动翻面**读完，再放回原处。
> **适用角色**：gameplay 程序（拾取与阅读流程）、美术（纸张与灰尘贴图、版面）、策划（文档文案与触发标记）。
> **上层规范**：[表现层驱动契约](../contracts/表现层驱动契约.md)（View 接口边界）、[运行时架构说明书](../运行时架构说明书.md)（命令队列与 WorldState）、指南 [03](../../guidelines/03-architecture-patterns.md) / [04](../../guidelines/04-unity-scripting-rules.md) / [18 → 09](../../guidelines/09-packages-systems.md)（uGUI）。
> **状态**：运行时与生成器已落地，EditMode 用例通过；场景接线与字体待补，见 §7。

---

## 1. 这套系统解决什么

参考图给的是**两张纸**：一张《地下网络》的假设手记，一张《环状扩张现象》的观察记录（带便条、照片、日期章）。
两张纸的**版面是同一套**，只有文案和可选区块不同。所以系统按"**一个页面预制件 + 一份文档资产**"拆：

| 层 | 谁负责 | 产物 |
|---|---|---|
| 内容 | 策划 | `ArchiveDocumentSO` 资产（标题、手写正文、英文转录、便条、日期章、签名、档案编号） |
| 表现 | 美术 / TA | `ArchiveDocument.prefab`（世界空间 Canvas）+ 纸张与灰尘贴图 |
| 流程 | 程序 | `ArchiveDocumentPickup`（被射线拿起）+ `DocumentInspectController`（举起、阅读、放回） |

新增一张纸 = 新增**一个 `.asset` + 一个预制件实例**，不写代码。

## 2. 运行时结构

```text
RootsDance.Archive
├── ArchiveDocumentSO          # 内容：一张纸上写的所有字 + 可选的手绘图
├── ArchiveDocumentKind        # 手记 / 观察记录 / 便条 —— 决定版面排布
├── ArchivePageLayout          # 纯数据：每种纸的排布、歪斜角度、字底的浅色块
├── ArchivePageBlock           # 一个"纸上的东西"与它的 rect 的绑定
├── IArchiveDocumentPageView   # 流程 → 页面 的唯一接口（不含任何 UI 类型）
├── ArchiveDocumentPageView    # uGUI 实现：按 Kind 摆放、按内容开关、擦灰
├── ArchivePaperLighting       # 把纸实际收到的光喂给墨（见 §2.2）
├── ArchiveDocumentPickup      # IInteractable：世界里那张纸
├── DocumentInspectController  # 四态阅读循环，挂在 Player 上
└── DocumentInspectMath        # 纯数学：举距、推拉、转动夹角（可单测）
```

### 2.1 整张纸是一个 Canvas，所有层都 unlit

一个 `ArchiveDocument` 实例是**一个 world-space Canvas**：纸、洗白块、照片、印章、胶带、文字，
全部是这个 Canvas 上的图层，全部 unlit。

**这是从一个不成立的方案退回来的结果，值得写下来。** 最初纸是一个 `HDRP/Lit` 的 quad 站在 Canvas 后面，
好让它吃手电、显出纤维法线。**合成是错的，而且错得不小：**

- 受光表面往 frame buffer 里写的是**场景亮度**（叠加 HDRP 的 pre-exposure 之后是几千的量级）；
- Canvas 图层写的是它被作者定成的 **0–1 颜色**；
- 后者叠在前者上，每一块洗白、每一枚印章、那张照片，都变成一摊暗斑。

实测：开洗白块时正文区域读数 **4505**，关掉洗白块 **8016** —— 洗白块把纸**压暗了 44%**，
而它的职责正好相反。这不是 shader 参数能调回来的：差的是一个 **pipeline pre-exposure 系数**，
而一个 uGUI shader 既读不到它，也不允许 include HDRP 头文件（指南 07 §9.4）。

所有层同处一个颜色空间之后，纸和墨**在构造上就不可能不一致**；而这本来就是 HDRP 支持的形态 ——
它只会把 Canvas 当 Unlit 渲染。

**放弃的是**纸的逐像素光照：手电扫过去不会在纤维法线上亮起来。normal / mask 贴图仍然照常烘焙，
留给日后愿意把纸做成受光道具（文字烘进 base map）的人。

### 2.2 纸怎么跟上房间的光

`ArchivePaperLighting` 采样纸正面实际收到的光（环境探针 + 一盏 key light 的 lambert 近似，
直接项除以 π 换算到同一单位），然后**给整张纸上色 —— 纸和墨一起变暗、一起变暖**，
所以它读起来是躺在世界里的一个物体，而不是一张贴在道具前面的贴纸。

分两路交出去，因为纸由两种材质绘制：

- **图形**（纸、洗白块、照片、印章、胶带）共用一份 `RootsDance/UI/ArchiveInk` 材质实例，光作为 `_PaperLight` 乘上去；
  同一个 shader 还做两件让墨"渗进纸"的事：**纸纹咬掉墨色**和**边缘晕开**。
- **文字**由 TextMeshPro 自己的 SDF 材质绘制，用不了那个 shader，所以光被折进它的顶点色。

该组件带 `[ExecuteAlways]`：Scene 视图、预览截图和游戏里看到的是同一套结果 ——
这不只是方便，**否则 Editor 里的渲染测试验的是一个永远不会发布的配置**。

采样每秒几次而不是每帧（用 `Time.realtimeSinceStartup`，Editor 里也走），且有亮度下限，
否则暗处的纸不是"暗"而是"空白"。

## 3. 阅读循环

```text
Idle ──BeginRead()──► Raising ──补间结束──► Reading ──Interact──► Lowering ──► Idle
                         │                    │                       │
                    纸飞到眼前            擦灰 / 推拉 / 转动 / 翻面      纸飞回原位
```

| 状态 | 发生什么 |
|---|---|
| `Raising` | 纸被 `SetParent` 到 `HoldAnchor`（头部子物体），从原位平滑补间到举起姿态；玩家已挂起 |
| `Reading` | `IArchiveDocumentPageView.BeginReading()` 触发擦灰；每帧读输入 |
| `Lowering` | 纸补间回**拾取时记录的世界姿态**，落位后恢复父级与玩家控制 |

输入全部复用工程内既有 action，**未改 `RootsDance.inputactions`**：

| 操作 | Action | 说明 |
|---|---|---|
| 拾取 / 放回 | `Player/Interact` | 与其它交互一致 |
| 推近 / 拉远 | `Player/Move`（Y 轴） | 在"举远"与"凑近读"两个距离之间移动 |
| 转动 | `Player/Look` | 有夹角上限，纸不会转到侧面看不见 |
| 翻面 | `Player/Attack` | 仅当预制件背面有内容（`Has Back Face`）时生效 |

`PlayerInputReader` 为此新增了一个 `FlipPressedThisFrame`，按**它做什么**命名而不是按 action 名 ——
工程范围 action 资产自带 `Attack`，而本作没有可攻击的东西。

举远与凑近两个距离都由同一个取景公式算出（`DocumentInspectMath.HoldDistance`），
所以**一张小便条和一张大图纸会占据同样比例的画面**，不需要逐张调。

## 4. 世界状态与叙事

- 读完（**放回之后**，不是拿起的瞬间）才 `RaiseFlagCommand(FlagOnRead)`。判定标准是"这张纸在玩家眼前待过"，不是"光标扫过"。
- `Required Flag` 非空时，纸在该标记升起前不可拾取（提示也不显示）。
- `Is Collected` 打开时纸读完即收走（`SetActive(false)`）；关闭则原样放回原处。
- 档案**暂不进勘察报告**：`ReportCategory` 目前只有环境采样与生物记录两项，加第三项会改动扫描仪报告的枚举与页签。要接的话，在 `ArchiveDocumentSO` 上加一个 category 字段并沿用 `AddReportEntryCommand` 即可，接口已经对齐。

## 5. 生成资产

三个生成器，都遵循工程既有的"**每次构建把配方重新套到同一路径上**"约定 —— GUID 不变，场景里已有的实例自动吃到新版本。**调配方，不要手改产物。**

| 菜单 | 生成 | 说明 |
|---|---|---|
| `RootsDance/Archive/Build Handwriting Font` | `Fonts/FZJingLei SDF.asset` | **静态**图集，只烘焙全部文档实际用到的字符（当前 178 个）。动态 CJK 字体资产会在运行时把新字塞进图集并写回资产文件 —— 那正是现有像素字体每次开工程都冒出一个 8 MB 无关 diff 的原因。代价：没写进文档的字不会显示，**加了新文案就要重跑这一条** |
| `RootsDance/Archive/Bake Paper Textures` | `Textures/Props/ArchivePaper_BaseMap.png`、`ArchiveDust_BaseMap.png` | 程序化占位：奶油纸底 + 纤维噪声 + 从边缘洇进来的水渍 + 撕边 alpha；灰尘层角落最厚 |
| `RootsDance/Archive/Build Document Prefab` | `Prefabs/Props/ArchiveDocument.prefab` | 世界空间 Canvas，版面见 §6 |
| `RootsDance/Archive/Create Document Assets` | `Data/Archive/DOC-001_UndergroundNetwork.asset`、`DOC-002_RingExpansion.asset` | 参考图两张纸的文案 |

两张贴图落在 `Textures/` 下，因此按纹理管线的 `<Set>_<Map>` 规则命名；
该 importer 会把类型强制为 Default 而非 Sprite，**所以页面用 `RawImage` 而不是 `Image`**。

## 6. 版面

页面画布 1000 × 1200 单位，对应实物 0.16 × 0.192 m。排布集中写在 `ArchivePageLayout` 里，
是纯数据，有单测保证**不越界、不互相压字、浅色块永远比字大一圈**。

参考图给的不是一张打印表格，而是**一张撕下来的纸上的拼贴**：

- **没有边框、没有页眉页脚栏。** 参考里没有任何印刷框线。
- **每一段字底下都有一块浅色的、边缘不规则的"洗白块"**（`WashOf`）。这是参考图最有辨识度的一点 ——
  字从不直接落在脏纸上，否则读不清。
- **所有东西都歪一两度**（`RollOf`）。全部摆正就读成印刷表格，不是档案。
- **后来加上去的东西**（照片、回形针、圆形墨印、胶带便条、日期章、边角的暗印、卷起的纸角、
  手写的档案编号）是直接压在纸上的，**没有洗白块** —— 这正是它们读起来"是后加的"的原因。

排布**按 `ArchiveDocumentKind` 分**，因为参考图里两张纸根本不是同一种东西：

| Kind | 参考 | 排布 |
|---|---|---|
| `FieldNote` | 图 1《地下网络》 | 标题在上，**手绘图横贯中部**，正文与英文转录在图下方，编号在左下角。没有照片 |
| `ObservationRecord` | 图 3《环状扩张现象》 | **照片用回形针别在左上**，圆形墨印在其右，文字在右半边，下方是胶带便条、日期章、边角暗印与卷角 |
| `Memo` | —— | 撕下的小条：只有标题、正文和编号 |

内容为空的区块**整块关掉**：没有签名就没有照片，没有便条文字就没有便条和它的胶带。

生成器一次产出整套贴图（`RootsDance/Archive/Bake Paper Textures`）：纸的 base / normal / mask、
灰尘、洗白块、图钉、胶带、圆形墨印、回形针、卷角 —— 全部程序化，是占位，等美术用实拍纸替换同名文件。

> **`Mathf.SmoothStep` 不是着色器里的 `smoothstep`。** Unity 的签名是 `(from, to, t)`，返回的是
> **from 和 to 之间**的值；`Mathf.SmoothStep(0.84f, 1f, r)` 无论 r 是多少都不会小于 0.84。
> 第一版贴图里图钉的 alpha 最大只有 41/255、圆形墨印整个看不见、整张纸偏棕，全是这一个误用造成的。
> 文件里所有阈值都走自己的 `Threshold(edge0, edge1, x)`，不要再直接调 `Mathf.SmoothStep` 做阈值。

## 6.5 折痕怎么调（不用改代码）

选中 **`Assets/RootsDance/Materials/Props/ArchivePaper.mat`**，Inspector 里直接拖：

| 滑杆 | 作用 | 当前 | 建议范围 |
|---|---|---|---|
| **Fold Warp** | **折痕把字剪切多少** —— 想让折痕对文字影响更大就调它 | 0.012 | 0.004–0.02 |
| Crease Line | 折谷那条细暗线的深浅 | 0.7 | 0.3–1.2 |
| Relief Strength | 面板之间明暗差多少（折痕最主要的视觉来源） | 1.6 | 0.8–3 |
| Fold Sheen | 折肩的反光 | 0.35 | 0–1 |
| Ambient Wrap | 背光面暗到什么程度（越小越硬） | 0.55 | 0.3–0.8 |

改完**立刻生效**，Scene 视图和 `RootsDance/Archive/Capture Page Previews` 都能看到 ——
`ArchivePaperLighting` 带 `[ExecuteAlways]`。

> **这些值不会被 Build All 覆盖。** 生成器只在**材质不存在时**写一次默认值；
> 之后每次构建只重新接线（贴图、光照方向），不动这几个滑杆。
> 想恢复默认：删掉 `ArchivePaper.mat` 再跑一次 `RootsDance/Archive/Build All`。
>
> **注意取舍**：Fold Warp 调大，横穿折痕的**小字**（英文转录 24pt）会先糊掉；
> 中文正文字号大，扛得住。要"折痕狠 + 转录还能读"，就把转录字号一起调大。

## 7. 已知缺口

| 缺口 | 影响 | 处理方 |
|---|---|---|
| **方正静蕾是商业字体** | `Fonts/FZJingLei.ttf` 由方正（北京北大方正电子）发行，发布游戏前需确认授权 | 制作人：确认商用授权，并把授权凭据按字体惯例放进 `Fonts/` |

| 手绘根系图没有资源 | `FieldNote` 的 `Diagram` 槽是空的，图 1 中部那张网还没有 | 美术：画一张带 alpha 的图，挂到文档资产的 Diagram 字段上 |

| 尚未接入勘察报告 | 读过的档案不进报告页 | 见 §4 |

## 8. 怎么试玩

1. 打开 `Assets/RootsDance/Scenes/Levels/PlayerTest/PlayerTest_Gameplay.unity`
2. 菜单 **`RootsDance/Archive/Set Up Playtest In Open Scene`**
   —— 给 Player 装上阅读器、在头部建好 `DocumentHoldAnchor`、在身前地上摆两张纸
3. 按 Play，**走近**纸张 —— 进入 2.5 m 提示自动出现 —— 按 **E**

> 拾取是**靠距离**触发的，和扫描、拾取道具一模一样（共用 `NearestInRange` 规则），
> **不是靠准星瞄**。文件是平摊在桌面/地上的，从眼睛水平打出去的射线会从它上方掠过 ——
> 第一版就是这样，人站在纸正上方按 E 完全没反应。射线依然可用（文件仍是 `IInteractable`），
> 但不能是唯一入口。

| 操作 | 键 |
|---|---|
| 拾取 / 放回 | **E**（走近自动提示，多张取最近的那张） |
| 凑近 / 拉远 | **W / S** |
| 转动纸张 | **鼠标移动** |
| 翻面 | **鼠标左键**（仅当预制件勾了 `Has Back Face`，默认关） |

> 这个工具**不保存场景** —— 摆道具是关卡负责人的事，两个人同时改一个场景就是冲突的来源
> （指南 11）。试完想留就自己存，不想留就不存。

## 9. 场景接线

Player 上：

1. 加 `DocumentInspectController`。
2. `Hold Anchor` ← 头部下新建一个空物体，**forward 朝视线方向**。
3. `Input` ← `PlayerInputReader`。
4. `Suspended While Reading` ← `PlayerLook`、`FirstPersonController`、`InteractionRaycaster`。

场景里每张纸：

1. 放一个 `ArchiveDocument.prefab` 实例。
2. `Document` ← `Data/Archive/` 下的资产。
3. 确认物体所在层在 `InteractionConfigSO.InteractableLayers` 里。

## 10. 测试

`Assets/RootsDance/Tests/EditMode/Archive/`：

- `DocumentInspectMathTests` —— 举距随占屏比与纸张尺寸的变化、推拉的方向与夹紧、转动的符号与上限。
- `ArchivePageLayoutTests` —— 每个区块都在纸内、两两不重叠、不共用矩形。

版面本身单测测不到，用 `RootsDance/Archive/Capture Page Previews` 直出 PNG 到 `Logs/Captures/`（该目录已被 gitignore）。

> **一个容易踩的方向问题**：Canvas 是**从它 forward 的背面**被看的 —— 原点上的 Canvas 配默认相机，
> 相机是**沿着** +Z 看过去的。所以举纸时纸的 forward 朝向视线**外侧**，阅读姿态是零旋转；
> 站到 forward 那一侧去看会得到一张镜像的纸。预览工具和阅读姿态都按这个约定。
