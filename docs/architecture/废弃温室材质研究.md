# 废弃温室材质研究

> 适用角色：技术美术、场景美术
> 相邻文档：[贴图管线](./tooling/贴图管线.md)
> 状态 2026-08-29 · 第一版，尚未落到资产上

## 1. 目标定位

材质目标是 **photorealistic environmental weathering / long-term moisture
deterioration / biological colonization**，不是「废墟风格贴图」。

区别在于：前者是「这栋楼在高湿度、暴雨、植物侵入的环境里放了十几年」，
后者是「绿色材质 + 红色噪声」。第一版温室材质就是后者，被否掉了。

**最关键的一点：真正好的 weathering 材质，第一眼的差别不在 Base Color，
而在光在不同区域的反射完全不同。** 所以重点是 Roughness variation、
Height breakup、layered masks、directional water flow，而不是颜色更花。

## 2. 退化是一条链，不是一张图

一块表面同时承载多个过程，按发生顺序叠加：

```
BASE MATERIAL → WEATHERING → WATER → OXIDATION → BIOLOGICAL GROWTH → SURFACE DAMAGE → DEBRIS
```

钢材的真实历程是
`bare metal → oxidation → patina → corrosion → rust → flaking / scale`，
**不是** `green metal → red noise`。第一版跳过了中间全部环节，所以像
「深绿色光滑物体上染了血」。

三类表面各自的层：

| 铁框架 | 玻璃 | 墙面 |
|---|---|---|
| Painted / Galvanized Steel | Glass | Concrete / Plaster |
| Sun bleaching | Dust | Paint |
| Oxidation | Mineral deposits | Rain runoff |
| Surface dirt | Rain streaks | Moss / Algae / Mold |
| Water streaks | Mud | Rust runoff |
| Rust → Rust peeling | Moss / algae | Peeling |
| Moss / algae | Condensation / mildew | Cracks |
| Scratches → Bare metal | Cracks / broken panes | Debris |

## 3. 检索词：材料 + 经历 + 环境

泛词（`rusty metal texture`、`old wall texture`、`abandoned building texture`）
出来的都是「游戏素材感」的东西。有效的构造是
**材料是什么 + 它经历了什么 + 在什么环境下腐蚀**：

| 现象 | 该搜 | 不要搜 |
|---|---|---|
| P2 斑驳氧化、尚未出红锈 | `mottled oxidized steel`、`weathered steel patina`、`weather-beaten steel` | `rusty metal` |
| P1/P8 雨水冲刷痕 | `rainwater runoff stains concrete`、`vertical water stains` | `dirty wall` |
| P10 红棕色垂直污痕 | **`iron oxide runoff`**、`rust runoff stains`、`rust streaks on wall` | `rust stain` |
| P7 墙皮脱落露底 | **`paint delamination`**、`exposed substrate`、`peeling plaster` | `cracked wall` |
| P4/P9 潮湿霉斑 | `mildew stained wall`、`damp moldy concrete PBR` | `dirty wall` |
| P5/P6 蒙尘玻璃 | **`hazy glass`**、`grimy window glass`、`dust accumulation on window` | `dirty glass` |
| P3 碎玻璃 | `shattered architectural glass`、`fractured window glass` | `broken glass` |

生物侵蚀要分清：**moss ≠ algae ≠ mold ≠ lichen**，四者的视觉结构完全不同。
Lichen 形成细碎、斑驳、贴附表面的 biological breakup，废弃温室里很常见。

## 5. 两个库都没有的层

检索确认 **水痕方向性冲刷** 和 **玻璃（蒙尘/雾化/碎裂）** 在 Poly Haven 和
ambientCG 都没有可用资产。这两层必须程序化生成：

- **Water runoff**：Substance 3D Sampler 的 Rust filter 已经把现象拆成
  `Rust Spread / Edge Influence / Rust Intensity / Peel Scale / Peel Normal /
  Peel Height / Drips / Drips Orientation / Drips Length`，其中 Drips 系列
  就是重力驱动的冲刷。比找一张「rust texture」强得多。
- **Glass haze**：玻璃不是把透明度降到 0.5，而是
  `micro-surface contamination → scattering → haze`，所以 Roughness、Normal、
  Opacity 三者都要变，而不只是 alpha。
- **Broken panes**：碎与不碎要混合，不能整排统一。

Substance 的 Metal Weathering 系统本身把
`Dust / Dirtiness / Edges Wearing / Paint Peeling / Rust / Rust Peeling`
分开处理，这个分类值得直接照抄成图层结构。

## 6. 下一步

1. 先建**铁框架**的分层材质（层数最多、面积最大、参考最明确）。
2. 每层用 curvature / AO / world-Z 梯度做遮罩，而不是整片均匀铺。
3. 验证方式：换不同光照角度看反射差异，而不是只看 Base Color 截图 ——
   Poly Haven 的材质制作标准也是这么要求的。
