## 这个标签记录什么

`v0.1.0-shenicest2026` 标记团队确认的 Game Jam 提交源码快照。
它以 [`e899d620`](https://github.com/AmanThuL/shenicest-2026/commit/e899d620a812adfb57629c2e17aed9ce8992253b)
的游戏内容为基础，补充图文 README、提交文案 Markdown 归档和三张原始提交图片，再将 `develop` 合入 `main`。
归档过程不修改游戏代码、场景、预制件、包版本或 Player Settings。

标签指向合入 `main` 后的提交，发布后保持不动。后续改进在 `develop` 继续，使用新标签发布。
名称中的 `shenicest2026` 区分本次活动快照与后续打磨版本；它也是 `0.1.0` 的预发布标识。

本次只归档源码与介绍文档，没有重新构建、上传安装包或创建附带二进制文件的 Release。
已有安装包的实际来源应以其 `build-info.json` 为准，不能仅凭这个源码标签认定二者完全一致。

## 已知问题与边界

当前保留的 10 项测试失败分布如下，不将本快照描述为全量测试通过的正式版：

| 范围 | 数量 | 现象 |
| --- | --- | --- |
| ChapterHouse 流程 | 5 | 测试预期的 `FirstMeeting` / `FlowerSprite` 节点未找到 |
| 温室内容配置 | 2 | 模型数量与关卡场景数量不符合旧测试预期 |
| 交互层检查 | 1 | 检查时没有找到预期触发器或交互对象 |
| 终端 UI | 2 | 主题名称、温室终端位置与测试预期不同 |

这些结果记录测试观察，不在此断定每项都是实际游玩缺陷或都只是旧测试需要更新。

macOS 是已有构建验证记录的平台。Windows IL2CPP 构建脚本及脚本测试已就位，但实际 Windows 编译与运行仍未验证，
详见[构建与打包说明](../architecture/tooling/build-and-packaging.md)。本次没有额外宣称低配置设备性能或跨平台运行保证。
