## 项目介绍

### 项目背景

![雾中的 Briggs 植物研究所入口](images/briggs-entrance.png)

### 项目原点

我们的创作起点，来自对“什么会被看见，什么会被记录”这一问题的观察。

在科学史中，知识并不总是以今天熟悉的专业机构、论文与正式署名的方式产生。18—19 世纪植物学逐渐普及的过程中，女性曾广泛参与植物采集、观察、分类、标本制作与知识交换。植物学一度是女性相对能够进入的科学领域，但随着自然科学进一步专业化、制度化，一部分由女性参与的植物实践逐渐被重新描述为业余爱好、家庭教育或辅助性劳动。她们参与了知识的形成，却未必以同样的方式进入后来被书写和保存的科学史。

这使我们开始关注一种并不只存在于历史中的现象：当一种知识无法被现有的分类、评价和记录体系完整描述时，被忽略的究竟是知识本身，还是我们观看它的方式？

菌类与菌丝网络为这个问题提供了另一重启发。我们通常首先注意到地表上短暂出现、拥有明确形态的子实体，却很难直接看见地下持续延展的菌丝网络。后者通过连接、交换与共生参与整个生态系统，却往往隐藏在可见结果之下。当生命的价值习惯性地通过可见成果、“生产”与“繁殖”进行理解时，那些发生在地下、关系之间以及漫长时间尺度中的照料、连接和互惠，又应该如何被看见？

这种“可见的结果与不可见的关系”逐渐成为项目最初的创作母题。

与此同时，《地球尽头的温室》《如果我们无法以光速前进》《一个女人认为自己是行星》等女性科幻作品，也影响了我们对于灾后世界的想象。相比以战争、征服、技术扩张或英雄拯救作为核心的末日叙事，我们更希望从植物、环境、研究、照料与关系出发，想象灾难之后生命如何继续存在，以及人类如何重新理解一个已经不再完全服从自身秩序的世界。

### 从创作观察到游戏问题

当我们开始把这些观察转化为游戏时，我们意识到，它们与游戏中一些习以为常的规则存在有趣的对应。

游戏中的“成长”通常意味着获得更高的等级、更强的能力和更多资源；“探索”往往意味着发现、收集和占有；环境中的异常通常意味着需要被修复、清除或恢复到预设状态。

于是我们提出了一个最初的设计问题：如果玩家的成长不是变得更强，而是不断发现自己原先理解世界的方式并不完整呢？

由此，我们将项目设计为一款以植物和生态关系作为探索语言的第一人称 3D 叙事解谜游戏。

玩家不是通过战斗征服遗迹，而是通过观察、采样、识别、实验和植物互动逐渐理解环境。玩家最初依赖官方数据库和调查系统认识世界，但随着探索深入，会不断遇到无法被既有模型完整解释的现象：不同植物之间彼此连接的地下网络、突破人工培养边界的生命、停止运行多年却依然稳定的生态，以及没有出现在正式研究记录中的历史。

因此，游戏中的成长主要表现为认知上的成长：从发现异常、尝试解释到获得证据、发现原有解释不足再修正自己的判断。

在核心谜题中，这种认知变化进一步成为实际操作。玩家需要根据自己在环境中获得的证据判断：究竟应该让已经变化的生态重新服从旧有模型，还是承认旧模型已经无法描述眼前仍在生长的世界。遗迹中的植物早已突破人工划定的培养范围，而旧规划与现实环境之间的差异正是玩家进行判断的重要依据。

### 为什么用游戏表达

我们最终选择游戏，不只是因为希望讲述一段关于植物、女性研究者和灾后生态的故事，而是因为这个问题需要玩家亲自做出判断。

如果通过文字或影像直接告诉玩家“旧有的分类可能是不完整的”“生命不应该只是资源”，玩家获得的是一个已经完成的结论。

而在游戏中，我们可以先让玩家学习并信任一套规则。

玩家使用官方工具识别植物、采集环境样本、更新调查报告，并逐渐习惯通过数据库、编号和标准化参数理解遗迹；随后，环境开始不断出现无法被这套系统完整解释的现象。玩家必须把数据库信息、植物状态、空间变化、私人研究记录和自己的观察结合起来，重新建立对世界的判断。

因此，我们希望让玩家经历对于“规则”认识的转变——我按照原来的规则行动，却亲自发现它已经无法解释眼前的世界。

最终，玩家完成调查后，官方系统会根据其采集到的真实数据，将这片区域总结为具有“持续性生态利用价值”，并建议进一步开展资源调查与利用评估。

这里并没有虚假的数据，但问题是：准确的数据，是否就意味着完整的理解？

这也成为项目最终希望留给玩家的问题：

当旧的规则无法解释一个仍在生长的世界时，我们选择修正世界，还是修正规则？

## 目标用户

本作的核心目标用户为 18–30 岁、偏好叙事体验、环境探索与轻度解谜的独立游戏玩家。他以女性玩家、剧情向玩家、文艺向单机玩家为主，拒绝爽感快餐玩法，追求氛围、思辨与沉浸式探索体验。

### 核心用户画像

#### 1. 喜欢观察、推理与自主发现的叙事解谜玩家

这类玩家享受从场景细节、环境变化和碎片信息中建立联系，而不是单纯按照任务箭头寻找下一个交互点。本作以“发现异常—形成判断—主动验证—修正认知”作为主要探索节奏，希望提供一种更接近调查与推理的解谜体验。

随着新的证据出现，玩家还会不断重新理解此前见过的空间与线索。因此，解开谜题带来的满足感不仅来自“找到答案”，也来自某个瞬间意识到：原来之前看到的一切，还可以这样理解。

#### 2. 偏爱人文科幻、生态题材与氛围叙事的玩家

本作尤其适合喜欢轻科幻、灾后生态与人文思辨题材的玩家。这类玩家通常也更愿意接受留白、碎片化叙事和需要主动拼合的信息结构。

与以战斗、生存竞争和英雄拯救为中心的灾后叙事不同，本作从植物、研究、记忆与生命关系出发理解灾后的世界。玩家面对的核心问题不是“如何击败这里的威胁”，而是“这里为什么仍然能够生长”“过去的人如何理解它”“我们今天又应该如何面对它”。关注自然与人类、掌控与共生、体系与个体的深层主题，愿意为剧情立意、世界观留白与思想内核付费。

#### 3. 关注女性叙事与非征服式游戏体验的玩家

游戏以一段被遗忘的女性植物学研究史作为重要叙事线索，但不会通过直接说教呈现主题。玩家通过私人信件、研究记录、空间遗留物以及官方档案之间的差异，逐渐发现那些没有进入正式历史的知识与关系。

这类玩家偏好无暴力、无血腥、氛围细腻、视角温柔的游戏叙事。认同女性研究者视角，偏爱以观察、陪伴、共生、思考为核心的玩法，区别于传统冒险游戏的掠夺式、征服式体验，注重情绪共鸣与剧情留白质感。

#### 4. 喜欢低操作压力、完整单机体验的轻度玩家

本作没有复杂战斗、等级养成或高强度操作要求，核心交互集中于移动探索、环境观察、植物识别、采样、实验与轻度空间解谜。

因此，即使玩家不是硬核解谜或动作游戏用户，也可以通过视觉线索、环境反馈和逐渐积累的信息理解谜题。我们希望降低操作门槛，，让玩家能够把注意力集中在环境、故事与自己的判断上。

### 核心体验需求

这些用户虽然可能因为植物、科幻、解谜或女性叙事等不同元素进入游戏，但我们希望最终满足的是同一种体验需求：

进入一个陌生而安静的世界，通过自己的观察发现异常、建立联系、验证猜想，并在不断深入的过程中发现：自己最初理解这个世界的方式并不完整。

因此，本作不以持续的即时刺激作为主要驱动力，而以好奇心、发现感、认知反转和沉浸感维持探索动力；不要求玩家拥有植物学知识，而是让玩家在游玩过程中逐渐学会“如何阅读植物与环境”。

本作核心目标用户为18–30岁、偏好叙事体验与轻解谜的独立游戏玩家，以女性玩家、剧情向玩家、文艺向单机玩家为主，拒绝爽感快餐玩法，追求氛围、思辨与沉浸式探索体验。

## 技术栈

#### 1. 开发引擎与基础环境

本项目为96小时Game Jam极限开发的3D叙事生态解谜游戏，整体技术选型围绕轻量化开发、高稳定性、快速迭代、氛围表现力优先的核心原则搭建，适配短周期Demo完整体验闭环开发，兼顾视觉表现、玩法机制与叙事系统落地，具体技术栈配置如下：

基于 Unity 6.3 LTS 开发，采用 C# 实现核心游戏逻辑，并以 URP 完成第一人称 3D 灾后生态环境的实时渲染。围绕“植物与生态关系作为探索语言”的核心体验，项目将程序系统、3D 场景与环境叙事结合，使玩家能够通过观察、调查和环境反馈理解并推进游戏。

#### 2. 游戏开发与交互：

Unity 6.3 LTS / C# / Unity Input System / Cinemachine / UI Toolkit。主要实现第一人称探索、物体交互、植物识别与采样、环境状态变化、生态谜题、事件触发以及官方调查报告等系统。

#### 3. 3D 美术与场景：

采用 DCC → Unity 工作流。主场景、核心建筑及关键探索空间由团队自主建模和搭建，并在 Unity 中完成材质、灯光、碰撞、交互与环境效果整合；非核心环境与装饰部分根据开发周期使用部分现成素材。3D 场景同时承担空间引导和谜题信息传递，使植物分布、生态边界、人工设施与环境变化本身成为玩家可以“阅读”的线索。

#### 4. 视觉表现：

基于 URP 构建污染区、植物研究所、温室及菌丝生态等不同环境状态，通过植被、材质、光照与环境效果的变化强化区域之间的视觉差异，并服务于无强制箭头的环境引导。

#### 5. 工程与协作

使用 Git + GitHub + Git LFS 进行版本管理，采用分支与 Pull Request 工作流；通过 Multi-Scene / Additive Scene 拆分不同开发区域，并结合 UnityYAMLMerge 降低多人并行编辑 Scene 与 Prefab 时的冲突。项目同时建立统一的 C#、目录结构、场景协作、性能及版本控制规范，以支持短周期内的多人并行开发。

#### 6. 项目管控与优化技术

针对Demo场景进行模型面数精简、特效层级优化、资源按需加载，保证低配置设备可流畅运行，无卡顿、无阻断性BUG。适配96小时极限开发周期，采用模块化分工开发，机制、美术、叙事、音频并行迭代，精准落地MVP核心功能，保障体验闭环完整。

## 创新点

本项目的创新来自题材表达与游戏机制两个层面的共同设计。

在题材上，我们将女性植物学史、生态关系与灾后科幻想象结合，以一座被植物与菌丝重新占据的废弃研究所为舞台，关注那些在正式记录之外仍然持续生长的生命、知识与历史。

在玩法上，我们进一步尝试将这些主题转化为玩家可以直接体验的规则：成长不一定意味着变强，植物不一定意味着资源，发现不一定意味着占有，而准确记录也不一定意味着真正理解。

我们希望玩家不是在游戏结束后才通过剧情“理解主题”，而是在探索、判断和解谜的过程中，已经亲自经历这些问题。

#### 1. 女性植物学史 × 生态科幻的题材与叙事视角

本作将女性植物学研究史、菌丝生态与灾后科幻放入同一个世界观中。

我们的灵感来自一个真实的历史观察：女性曾长期参与植物采集、观察、分类和知识传播，但随着科学逐渐专业化、制度化，其中一部分实践被重新定义为业余、家庭或辅助性劳动。她们参与形成的知识并没有完全消失，却未必以同样的方式进入后来被认可和保存的历史。

菌丝网络与植物生态则为这一问题提供了另一层自然隐喻——地表可见的生命只是整个生态的一部分，在地下还存在着难以直接观察，却持续发生连接、交换与共生的关系网络。

因此，本作没有选择传统灾后游戏中常见的生存竞争、资源争夺与英雄拯救作为核心，而是从一名植物研究者的视角进入废墟，通过植物、研究、私人通信和环境遗迹重新理解灾难之后仍然延续的生命与知识。

这里的女性历史也不是作为背景文本附着在玩法之外。随着调查深入，玩家逐渐发现：今天仍在维持生态的知识，与那些没有被完整写入正式历史的研究之间存在联系。

#### 2. 以「认知成长」替代传统数值成长

我们不拘泥于传统解谜游戏“找道具、开机关、提示引导”的固化模式，尝试重新理解游戏中的“成长”，构建观察—假设—验证—认知重构的完整科研式探索闭环。玩家以植物研究者的思维开展探索，通过采样、识别、环境比对完成逻辑推理与假设验证，使解谜从机械操作转变为认知迭代与科学探究，实现玩法、人设、世界观的高度统一。

新的信息因此不仅意味着“获得一条线索”，还可能改变玩家对已经见过的线索的理解。本作希望让玩家获得一种不同于数值升级的成长体验：不是“我现在更强了”，而是“我现在看见了以前看不见的东西”。

#### 3. 植物不是资源，而是「阅读世界的语言」

区别于多数游戏将植物作为装饰、资源或道具的浅层设计，本项目将植被、根系、菌丝体系升级为解读遗迹历史与生态真相的核心媒介，让植物自身成为环境信息的一部分。

植物的生长方位、长势差异、边界突破形态、人为采样痕迹与生态制衡关系，均可反向推导场地环境演变、前人实验轨迹与仙女环生态运作规律。植物同时承担线索载体、解谜核心、世界观证明与叙事载体多重功能，随着游戏推进，玩家实际上是在逐渐学习一套新的“生态语言”，并利用这种语言阅读空间、发现路径和理解历史。

#### 4. 「生态协商式解谜」：从征服环境到理解环境

在传统冒险游戏中，环境障碍常遵循“获得能力—破坏障碍—继续前进”的结构。本作尝试建立另一种关系：玩家不是消灭阻碍自己的生命，而是理解它为什么会产生这种行为，并利用生态关系使其主动发生改变。

例如，面对具有自我修复能力的活体菌丝屏障，单一植物作用无法将其解除。玩家需要理解不同物种释放的生态信号，将具有亲和作用与抑制作用的信号组合，使菌丝网络改变自身状态并主动退让。

我们将这种设计概括为：生态协商式解谜（Ecological Negotiation Puzzle）：不是征服环境，而是理解环境如何响应。

这一逻辑也延伸到大型环境谜题中。当植物已经突破过去人工规划的培养边界时，玩家真正需要判断的不是“哪个按钮才是正确答案”，思考当现实已经改变，我们应该让现实重新服从模型，还是让模型重新学习现实？

于是，游戏的主题不再只是存在于剧情文本中，而直接进入了玩家解决谜题时所遵循的规则。

#### 5. 双重记录系统：让「谁定义知识」成为玩法

本作同时设置了官方调查报告与个人植物手记两套记录系统。官方报告记录物种编号、污染数据、设施状态、异常指标与资源价值；个人手记则逐渐记录植物之间的关系、研究者留下的痕迹、无法被数据库解释的现象，以及主角不断发生变化的判断。

官方系统并不是一个简单的“错误系统”。它可以准确回答“这是什么”“数值是多少”“是否具有利用价值”，却很难回答“为什么它们能够共同存在”“这些知识从哪里来”“什么没有进入正式记录”。

随着游戏推进，两套系统对于同一个世界逐渐形成不同的描述。最终，当官方系统准备把玩家发现的一切重新整理为可调查、可开发、可利用的信息时，“记录”本身也成为玩家必须重新思考的行为：发现一种生命、知识或历史之后，我们应该如何记录它？而记录它，是否也意味着重新定义甚至占有它？

### 创新的整体价值：

我们不仅希望选择一个较少被游戏表现的题材，也希望为这个题材寻找只属于游戏的表达方式。

女性植物学史与生态科幻构成了作品的题材创新；从“征服与占有”转向“观察、关系与共生”构成了作品的视角创新；认知成长、植物环境语言与生态协商式解谜构成了玩法创新；官方报告与个人手记则进一步让叙事主题进入游戏规则本身。

最终，这些创新共同服务于同一个核心问题：

当旧的规则无法解释一个仍在生长的世界，我们选择修正世界，还是修正规则？

## 团队分工

![Briggs 研究所建筑展示](images/briggs-architecture.png)

本项目为96小时极限GameJam开发项目，团队分为策划组、美术组、程序组三大模块，各组权责清晰、并行协作、高度配合，保障项目在短周期内完成完整Demo闭环体验，具体分工如下：

### 一、策划组

负责项目整体框架搭建、玩法设计、叙事内容制作与项目进度统筹，把控游戏核心体验与整体调性。

1. 核心设计：敲定项目整体玩法机制，设计「观察—假设—验证—认知重构」核心探索循环，搭建生态解谜规则、双记录系统、认知反转叙事体系，确定MVP核心功能与可删减内容，严控96小时开发范围。

2. 关卡与流程设计：规划研究站、温室、实验室、地下菌丝区域整体探索动线，设计全流程谜题逻辑、异常交互节点与探索触发顺序，保障玩家认知递进体验完整闭环。

3. 叙事与文案制作：撰写全套世界观背景、玩法说明、植物扫描文案、实验日志、研究员手记、官方报告与私人手记内容，统一全文案叙事风格与思辨主题。

4. 项目统筹与落地：对接美术、程序同步需求，跟进各模块开发进度，试玩测试并优化体验细节，收尾项目路演文案、项目文档整合与成果输出。

### 二、美术组

负责项目所有视觉表现、场景氛围、动态特效与材质渲染，打造贴合温柔废土、生态叙事的专属美术风格。

1. 3D场景搭建：完成研究站、废弃温室、廊道、地下菌丝核心区域模块化搭建，还原“人工设施被自然植被侵占”的视觉叙事效果，匹配关卡探索动线优化场景布局。

2. 模型与资产制作：制作植物、菌丝、实验设备、废弃道具等核心场景资产，贴合灾后生态研究站设定，统一模型风格与精度标准，适配Demo轻量化运行需求。

#### 3. 材质与氛围渲染：调试场景光影、氛围材质，制作积灰、老旧、湿润、通透菌丝等质感表现，搭建整体静谧、隐秘、沉浸式的探索氛围。

#### 4. 动态特效制作：制作植物生长、生态微光、试剂融合、菌丝收缩、光场交互等核心VFX特效，联动玩法机制，实现生态逻辑可视化表现。

5. UI视觉设计：制作植物扫描界面、实验图纸、报告面板、手记界面等功能性UI，贴合项目科研生态主题，保证界面简洁直观、适配叙事展示。

### 三、程序组

负责所有玩法功能、交互逻辑、系统框架开发与性能优化，实现策划设计的全部核心机制，保障项目稳定运行。

1. 基础交互框架开发：搭建玩家移动、场景交互、物品拾取、工具调用、扫描采样、植株交互等基础功能，统一全游戏交互逻辑，适配快速迭代开发。

2. 核心玩法开发：实现植物状态生长模拟、生态制衡解谜逻辑、环境异常判定、线索触发与进度解锁机制，落地「观察验证式」核心解谜玩法。

3. 核心系统开发：搭建双记录系统逻辑，实现官方探索报告数据自动收录、私人手记内容存储与留存，完成结局抉择机制、进度存档逻辑开发。

#### 4. 叙事与UI功能实现：对接文案资源，实现线索弹窗、日志阅览、图纸展示、植物档案、剧情文本动态触发与进度解锁功能。

5. 性能优化与Bug修复：针对场景模型、特效、资源进行轻量化优化，排查并修复阻断性Bug，保障Demo流畅稳定运行，完成最终打包输出。

## 开发过程

本项目在 96 小时 Game Jam 周期内完成。面对 3D 游戏在场景、程序、玩法与叙事整合上的开发压力，团队没有追求一次性完成所有设想，而是先确定 Demo 必须成立的核心体验，再将玩法、程序、美术和叙事拆分并行制作，并通过持续整合与试玩逐步完成最终版本。

整体开发过程可以分为四个阶段：

#### 1. 核心体验确认与 Demo 范围收束

项目初期，团队首先统一游戏的核心定位，并将较大的世界观与主题研究收束为一个可以实际验证的体验目标：玩家能否通过观察植物与环境、提出判断并主动验证，在探索过程中不断修正自己对世界的理解？

围绕这一目标，我们确定了“探索—发现异常—调查—判断—验证—认知更新”的核心玩法循环，并主动控制 Demo 的开发范围。战斗、复杂数值成长、大规模开放区域等与核心体验关系较弱的系统没有进入当前版本；开发资源优先投入到第一人称探索、植物观察与调查、生态解谜、环境叙事、双重记录以及最终选择等关键内容中。

同时，策划组完成玩法机制、关卡动线、谜题逻辑、叙事文案与项目文档体系搭建，团队梳理完整体验流程与关键节点，以一个能够从进入遗迹、建立调查规则，到逐渐发现异常、修正认知并完成最终选择的完整可玩 Demo作为共同开发目标。

#### 2. 玩法、程序、美术与叙事并行制作

核心流程确定后，项目进入多模块并行开发阶段。这一阶段各模块围绕同一条玩家动线持续交换可用版本，使关卡、美术、程序与文本能够同步调整。

策划与叙事侧继续细化关卡动线、植物机制、谜题条件、调查内容、环境线索与文本，并根据实际实现情况持续调整信息密度和流程节奏。

程序侧基于 Unity 搭建第一人称移动与交互框架，并逐步实现植物识别与采样、调查对象、环境状态、谜题触发、剧情事件、报告与手记等核心系统，为后续内容快速接入提供基础。

3D 美术与场景侧则同步进行灰盒验证、主建筑与核心空间制作、场景搭建、材质灯光和生态环境表现。核心建筑与主要探索空间由团队自主制作，同时在非核心环境内容中合理使用现成资产，将制作时间集中到真正影响探索体验与视觉识别的区域。

#### 3. 从独立功能到完整游戏体验

中后期的重点从“功能是否能够运行”转向“这些功能组合起来之后，是否真的形成了我们的核心体验”。

团队开始将植物生态规律、空间设计、调查工具与谜题状态进一步整合。例如，植物不再只是一个可以扫描并返回信息的对象，它的分布、生长状态和与其他生命的关系也需要成为玩家判断环境的依据；谜题的完成也不只是触发机关，而需要通过植物、菌丝、设施与环境变化给予玩家能够观察到的反馈。

叙事内容同样在这一阶段进一步进入玩法。研究记录、私人信件、环境痕迹不再单独承担“讲故事”的功能，而是与玩家正在调查的问题相互印证；官方调查报告与个人植物手记则分别记录同一次探索中不同层面的信息，使两套记录之间的差异随着流程推进逐渐显现。

通过这一阶段的整合，最初分别开发的探索、植物调查、生态解谜、环境叙事与记录系统被串联成同一条玩家体验。

#### 4. 完整流程试玩与体验打磨

进入开发后期后，团队将主要精力转向完整流程试玩，而不再继续扩张功能范围。

测试重点不仅包括流程阻断、触发异常、场景碰撞和功能 Bug，也包括一些更直接影响本作体验的问题：玩家是否能够注意到关键植物？是否能够理解环境发生了什么变化？谜题给出的信息是否足够形成判断？文本是否说得太多或太少？没有强制任务箭头时，玩家是否仍然知道自己应该探索哪里？

针对试玩结果，团队持续调整植物与场景线索的可读性、交互反馈、谜题提示、文本出现时机、环境引导与整体探索节奏，并同步进行场景、模型、灯光与运行性能方面的优化。

最终，我们希望 Demo 达到的并不是“展示尽可能多的功能”，而是让玩家能够从头到尾完整经历一次：

进入未知环境 → 学会调查 → 发现既有解释的局限 → 利用新的证据理解生态 → 修正自己的判断 → 面对最终选择。

## 后续计划

当前 Game Jam Demo 主要用于验证三个核心设计是否能够成立：以认知变化驱动探索、以植物与生态关系构成谜题，以及通过不同记录方式让玩家重新思考“什么是有效知识”。

如果项目继续开发，我们不会单纯通过增加地图和文本扩充内容，而会围绕这套已经建立的核心机制继续深化。

#### 1. 深化植物与生态解谜机制

现阶段 Demo 已经建立了通过植物特性、环境状态与物种关系进行探索和解谜的基础框架。后续将进一步丰富植物之间的共生、竞争、信号传递、环境适应与群落变化，让生态关系本身产生更多可观察、可推理、可利用的玩法可能。谜题设计也将逐渐减少“一种植物对应一种固定功能”的方式，增加不同环境条件与物种关系之间的组合。玩家需要先观察现象、提出假设，再通过实验和环境反馈验证自己的判断。

我们希望最终形成更完整的“生态协商式解谜”：玩家面对的不是等待被清除的障碍，而是一个具有自身运行规律的生命系统；解决问题的关键，在于理解它如何响应。

#### 2. 完善以知识为核心的「认知成长」系统

后续版本将进一步强化本作区别于传统数值成长的“认知成长”。

玩家在早期获得的植物记录、生态规律、研究资料与环境经验，将不仅承担剧情信息功能，还能够参与后续区域的判断与解谜。随着知识不断积累，玩家能够识别过去无法理解的生态模式、建立更复杂的假设，并重新解释曾经调查过的空间与历史。

我们希望进一步验证一个核心设计方向：知识本身，能否像传统游戏中的技能与装备一样，成为真正具有玩法价值的成长资源？由此让“越来越能够理解这个世界”本身，成为玩家持续探索的重要动力。

#### 3. 深化双重记录与玩家选择

现有 Demo 中的官方调查报告与个人植物手记将继续作为后续叙事系统的重要核心。

未来版本中，两套记录不仅呈现不同的信息，也可以进一步与玩家行为产生联系：哪些发现进入正式报告、如何描述某种异常、哪些关系被保留下来，以及调查结果如何被安全区重新解释，都可能影响后续任务、机构反馈乃至故事走向。

最终选择也将避免被简化为“提交 / 不提交”“开发 / 保护”的善恶二选一。我们希望建立更复杂的处境：知识需要被记录才能得到保存，但进入制度与资源体系，也可能意味着它再次被分类、定义和利用。

这样，结局不再是流程末尾突然出现的一道选择题，而是玩家此前所有观察、怀疑与认知变化的自然结果。

#### 4. 扩展遗迹、生态区域与完整世界

当前植物研究所代表的是完整世界中的第一个核心调查区域。未来可以围绕安全区边界、菌丝生态以及灾后研究历史，继续扩展具有不同生态特征和历史背景的遗迹。

每个区域都可以围绕一组新的关系展开：新的生态现象 → 既有知识无法完整解释 → 调查与验证 → 发现新的生命关系 → 被遗漏的历史浮现 → 玩家重新建立理解。不同区域不会只是更换场景与植物，而会引入新的生态规律和观察方式。随着多个调查地点的信息逐渐连接，玩家也将从一座研究所的局部历史，逐渐理解安全区的形成、菌丝网络的发展，以及不同研究者与知识网络之间更大的联系。

这一结构使当前 Demo 所验证的核心循环能够自然扩展，而不必依赖简单增加关卡数量或重复谜题。

#### 5. 体验优化与正式版本适配

在内容扩展之外，后续开发也将持续进行完整的体验与产品化打磨。

技术层面将进一步优化运行性能、场景加载、第一人称移动与交互手感，并根据目标发布平台进行性能与操作适配，保证复杂植被与 3D 环境下的稳定运行。

体验层面将通过更多玩家测试完善新手引导与环境信息的可读性。本作仍会保留弱 UI、少任务箭头、鼓励玩家主动观察环境的设计方向，但会进一步优化视觉引导、交互反馈和渐进式教学，在不直接给出答案的情况下，让玩家更自然地理解“应该观察什么”以及“如何验证自己的判断”。

叙事层面则将继续优化最终选择的前置铺垫、行为反馈与结局留白，使植物研究、女性历史、官方记录与玩家个人理解最终汇聚到同一个选择中，并在游戏结束后保留足够的情绪余味与思考空间。

最终，我们希望将当前的 Game Jam Demo 逐步打磨为一款在核心玩法、叙事表达、视觉氛围与运行体验上均具备完整性的独立 3D 叙事解谜作品，并为后续正式发布做好准备。

### 未来愿景

当前 Demo 对我们而言并不是一个完整世界的缩小版，而更像是对一套游戏设计语言的第一次验证。

如果项目继续发展，我们希望每一个新区域带给玩家的，不是一个更强的敌人，而是一种此前无法理解的生命关系；每一次成长，也不是获得更高的数值，而是获得一种新的观察、判断和理解世界的方法。

最终，我们希望沿着当前原型继续回答游戏最初提出的问题：

当旧的规则无法解释一个仍在生长的世界，我们是让世界重新服从规则，还是学会用新的方式理解它？

- 游戏玩法说明:

### 01｜核心玩法

### 一场从“调查”开始，到“理解”结束的探索

本项目是一款以植物与生态关系作为探索语言的 3D 叙事解谜游戏。

家扮演一名受安全区派遣的植物研究者，进入一座长期废弃的生态研究遗迹，通过观察环境、识别植物、采集样本、阅读研究痕迹并利用不同生命之间的生态关系，逐步深入遗迹并重构这里曾经发生的历史。

玩家不会通过旁白直接获得遗迹的历史，而需要在空间中主动寻找答案：观察植物的生长状态，辨认根系与菌丝的蔓延，检查研究设施与资源采集痕迹，读取不同年代留下的研究记录，并使用采样、识别等工具验证自己的判断。

游戏不设置战斗、等级或传统数值成长。玩家的主要成长来自认知变化：随着新的环境证据不断出现，原本已经“看懂”的植物、设施与历史痕迹会获得新的含义。玩家不是通过变得更强来进入下一个区域，而是通过知道得更多、看得更深、修正此前的判断继续前进。

当调查趋近尾声，玩家的核心疑问将不再是「这里曾经发生了什么」，而是「知晓全部真相后，我该如何面对」。

### 玩家目标

玩家最初的明确任务是：进入废弃植物研究所，完成生态与资源调查，并形成调查报告返回安全区。

但随着探索深入，玩家会发现调查对象远比官方任务描述复杂：植物正在突破过去人工划定的生长边界；地下菌丝形成了现有数据库无法完整解释的生态网络；研究所中还残留着一段没有进入正式历史的女性植物学研究记录。

因此，玩家的目标会逐渐从“完成一次资源调查”转变为“理解这里究竟发生了什么，以及自己应该如何记录所发现的一切”。

### 基础操作

游戏采用第一人称探索方式，保持较低的操作门槛，让玩家将注意力集中于环境观察和信息判断。

玩家主要进行移动与视角观察、调查环境对象、使用识别/采样工具、阅读研究记录、操作研究设施、使用植物或实验产物与环境互动，以及查看官方调查报告和个人植物手记。

游戏尽量减少持续任务箭头和强制路径提示。可探索方向主要通过植被密度、植物生长状态、地形结构、光照、声音、人工痕迹与环境变化进行引导，使“观察空间”本身成为操作的一部分。

### 关键交互

游戏中的关键交互主要围绕“观察—验证—理解”设计。

#### 1.植物识别与环境采样：

玩家可以使用研究设备识别植物、采集土壤与环境样本，获得物种、污染程度、生长状态等调查数据。相关结果会进入官方调查系统。但随着探索深入，玩家会逐渐发现：识别一个对象，并不意味着理解它与环境之间的关系。

#### 2.植物与生态互动：

植物不是单纯的收集物或消耗型道具。玩家需要观察根系方向、生长范围、形态变化、共生状态与群落分布，从植物本身读取空间和生态信息，并利用这些关系解决环境谜题。

#### 3.生态实验：

面对部分活体生态障碍，玩家需要结合不同植物产生的信号与作用进行实验。例如通过不同生态信号的耦合改变菌丝网络状态，使其主动退让。玩家不是简单“破坏障碍”，而是在理解环境规律后促使其产生响应。

#### 4.设施操作与环境反馈：

部分大型谜题要求玩家结合旧规划图、维护记录和当前植物状态判断设施应该如何运行。操作后，植物、菌丝、设备、声音和空间状态会共同反馈结果，而不是简单弹出“正确 / 错误”。

#### 5.调查报告与个人手记：

玩家的调查同时进入两套记录系统。官方报告记录分类、环境数据、设施状态与资源价值；个人植物手记则记录关系、疑问、研究历史和主角不断变化的理解。随着探索推进，两套系统对同一个世界逐渐形成不同描述。

### 通关条件

玩家需要完成研究所主要区域的探索，取得足够的生态与历史证据，解决阻碍调查路线的关键生态谜题，并完成对核心区域的调查。

当玩家逐渐理解植物、菌丝、安全区边界与过去研究之间的关系后，将形成最终调查结果。此时，游戏把最初的任务重新交还给玩家：是否将自己的调查发现提交给派遣自己前来的安全区系统？这一选择构成当前 Demo 的最终节点。

通关的重点并非击败最终敌人或达到某个数值，而是完成一次完整的认知变化：玩家最初作为一名相信调查系统的研究者进入遗迹，最终需要根据自己亲眼看到、亲自验证和重新理解的一切，决定应该如何处理这份知识。

### 02｜核心玩法循环

游戏的核心玩法由两个连续的循环构成。

### 第一重循环：认识世界

```text
探索空间
↓
发现异常
↓
观察植物、环境与人工痕迹
↓
形成判断 / 提出疑问
↓
使用植物或研究工具验证
↓
获得新的信息 / 改变环境状态
↓
进入新的区域
↓
重新理解此前发现的线索
```
玩家进入新的区域后，会首先通过植物生长状态、空间结构、人工设施或异常生态现象发现“不协调之处”。例如，一片本不应稳定生长的植被、一组跨越多个物种的地下根系网络，或者已经突破原有人工培养边界的植物群落。地下观察窗中，多种植物根系甚至呈现出持续连接、且超出现有数据库识别范围的网络结构。

玩家随后利用识别器、采样设备、历史记录以及自身的植物学观察形成初步判断。工具能够回答“这是什么”“污染程度是多少”“是否符合数据库”，但往往无法解释“为什么它会在这里”“为什么不同生命会产生这种关系”。这种已知信息与现场现象之间的缺口构成持续探索的动力。

获得线索后，玩家需要进一步利用植物特性、生态信号或环境关系进行验证。谜题的解决并不只是打开一道门，同时也会改变玩家对遗迹的理解。此前看似普通的采样痕迹可能被重新理解为资源收割；被系统判定为“异常”的植物，也可能实际上正在形成一种新的稳定生态。

因此，每一个局部谜题都遵循一个更深层的循环：

获得答案 → 发现答案并不完整 → 提出新的问题。

---

### 第二重循环：面对世界

当玩家逐渐完成调查，所有重要事实已经被记录进官方探索报告。

此时游戏不再询问：“你找到答案了吗？”

而是询问：“你已知晓全部真相，接下来要如何抉择？”

玩家最终面对是否提交调查报告的选择。

这个选择并不决定世界的存亡，也不是简单的“正确 / 错误”道德选择。

玩家无法拯救这个世界，也无法凭借一次选择决定生态系统和人类社会的未来。

玩家只是一个调查者。

她能够决定的，是自己是否将已经获得的知识交回原本派遣自己的系统。

因此，游戏真正关注的是：一个人在理解世界之后，是否还会以进入这个世界时的方式行动。

---

### 03｜亮点玩法一：植物不是道具，而是“探索语言”

本游戏最核心的玩法创新，是将植物从传统游戏中的装饰、资源或收集品，转变为玩家解读空间的媒介。

玩家需要观察：

- 植物在哪里生长；

- 它向哪里生长；

- 根系如何延伸；

- 哪些植物异常旺盛；

- 哪些植物已经突破人工划定的边界；

- 哪些植物曾经被采样、切割或移植；

- 植物与水体、土壤、菌丝以及建筑之间存在怎样的关系。

这些信息共同构成一种新的“地图”，让玩家从「找通关物品」转变为「探索生态规律、找寻空间历史」

最终形成：

阅读植物 → 推断环境变化 → 验证猜想 → 推进探索

植物因此同时承担：

世界观、空间线索、解谜核心与叙事载体。

---

### 04｜亮点玩法二：以观察验证解谜，告别提示式答案

游戏中的谜题建立在观察与验证之上。

玩家进入一个新的区域后，首先面对的不是明确的任务箭头，而是一个需要解释的异常：

- 一条无法继续前进的路径；

- 一片异常生长的植物；

- 一处失效的设施；

- 一段颜色特异的根系；

- 一组无法解释的环境数据。

玩家需要先观察环境，再提出自己的判断。

随后，可以利用：植物知识 + 采样工具 + 识别工具 + 环境信息对判断进行验证。

例如：

玩家在废弃廊道墙缝发现成片焰苔，异常集中生长在菌丝大门与根节点周边。

通过识别、采样工具检测，验证焰苔拥有抑制、驱离菌丝的特殊生态特性。

结合场地环境与植物知识判断：焰苔只在菌丝活跃区域旺盛生长，二者存在特殊生态制衡关系。

玩家得出结论：菌丝屏障并非固定障碍，可通过焰苔的特殊生物信号进行干涉、解除封堵，以此打通封闭通路。

这里不存在单纯的“点击正确物品”。

玩家真正完成的是：发现现象 → 提出假设 → 找到证据 → 得出结论。

这也是主角作为植物研究者的核心行动方式。

---

### 05｜亮点玩法三：空间本身就是一份历史档案

游戏不通过连续的剧情演出来告诉玩家“这里曾经发生过什么”，遗迹本身就是历史档案。

玩家可以从：研究记录、前人手记和书信、实验图纸与报告、植物样本、资源标记、废弃实验设备、温室结构中拼合不同阶段的历史。

玩家看到的是不同时间留下的痕迹同时存在于同一个空间里，玩家的认知会层层反转，逐渐深入。

玩家可能第一次认为：“这里曾经进行过正常的植物采样研究。”后来发现：“这里曾经存在相关实验研究。”再后来试图假设：“零散的采样痕迹，是前人有目的、成体系的生态资源收集实验。”

于是此前看似普通的空间突然获得了新的意义。

空间不是承载故事的容器，空间本身就是故事。

---

### 06｜亮点玩法四：“记录”本身设计为叙事机制

本作同时设置了官方调查报告与个人植物手记两套记录系统。官方报告记录物种编号、污染数据、设施状态、异常指标与资源价值；个人手记则逐渐记录植物之间的关系、研究者留下的痕迹、无法被数据库解释的现象，以及主角不断发生变化的判断。

官方系统并不是一个简单的“错误系统”。它可以准确回答“这是什么”“数值是多少”“是否具有利用价值”，却很难回答“为什么它们能够共同存在”“这些知识从哪里来”“什么没有进入正式记录”。

随着游戏推进，两套系统对于同一个世界逐渐形成不同的描述。最终，当官方系统准备把玩家发现的一切重新整理为可调查、可开发、可利用的信息时，“记录”本身也成为玩家必须重新思考的行为：发现一种生命、知识或历史之后，我们应该如何记录它？而记录它，是否也意味着重新定义甚至占有它？

---

### 07｜亮点玩法五：谜题有标准答案，结局无固定选择

游戏前期解谜拥有客观正确答案，贴合科研严谨性：玩家需要依据完整线索、数据、环境逻辑做出判断，判断正确即可推进流程，错误则无法解锁新内容。

例如：在温室核心区域，玩家需要根据此前获得的植物分布、环境数据、维护记录与空间信息，判断当前生态系统应该采用哪一种循环方案。

如果判断错误，系统无法正常运行。

如果判断正确，生态循环重新建立，玩家得以进入新的区域。

但解谜的终点不是游戏的终点。前期谜题解决的是「什么是真相」，而最终结局选择解决的是「知晓真相后，我该如何行动」。

真正的核心抉择，永远在找到答案之后。

---

### 08｜亮点玩法六：玩家不是救世主

本游戏摒弃「玩家拯救世界」的寻常套路，把玩家的选择与“人类命运”解绑。

最终选择并不会改变世界格局：安全区、人类社会以及生态系统，都不会因玩家的单次选择而覆灭或重生。

玩家只是一个偶然进入这里的研究者，见证了无人知晓的过往，女性研究者的付出、植物的过往、末日生存必然的功利性，以及自身调查行为与历史的相似性。一处处同构，一处处投射，一处处隐喻，构建起过往与当下，虚构与现实的联系。

最终选择无关拯救，我们回到个人的语境，我们如何理解这个世界的真相，然后选择如何面对这个世界。

---

### 09｜玩家成长：以“认知成长”替代数值成长

玩家没有等级、战斗力或装备树。真正的成长体现在对世界模型的不断修正。同一个空间会因为后来获得的新证据而产生新的意义。游戏中的核心谜题甚至要求玩家判断：究竟是现实出现了错误，还是过去用于解释现实的模型已经失效。中央温室的循环系统便以此为基础——玩家需要根据环境调查、旧规划图与维护记录判断，当前生态已经突破原有“核心培育”与“标准环形”模型，并选择是否承认正在扩展的新边界

因此，玩家真正获得的不是一把更强的工具，而是一种新的阅读游戏与真实世界的方式。

玩家的终极成长：从「看见表面现象」到「读懂底层逻辑」，从「被动完成任务」到「反思自身行为」，掌握全新的认知世界、解读世界的方式。

---

### 10｜一句话总结核心玩法

探索遗迹，阅读植物，验证真相；在完全知晓真相后，决定自己的最终取舍

我们让玩家通过植物找到答案，却把真正的选择留到了答案之后。
