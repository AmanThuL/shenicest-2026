# 00章后段流程：首次采集至进入研究所

> 范围: 第一次采集与官方记录之后，至玩家进入研究所检修通道
> 文档类型: Flow Design / 阶段验收
> 来源: 主策划流程总览（飞书同步文档，见 §1.1）
> 状态: 已入库，与 [00章室外环境设计](./00章室外环境设计_起始点至检修通道前.md) 配套使用

## 1. 阶段目的

本阶段承接 00 章前段已经完成的“进入遗迹最外部低污染区 — 第一次识别 — 第一次采样 — 官方报告更新”流程，
使玩家从对遗迹生态环境的初步调查，进一步进入真正的探索状态。

流程切片为：

```
新生植物调查 → 发现研究所 → 研究所外围探索 → 获取环境线索
→ 发现两种不同爬藤植物 → 识别细小爬藤植物的生长规律
→ 结合建筑环境判断入口位置 → 掀开覆盖植物 → 发现检修入口 → 进入研究所
```

这一段是 00 章的第一个环境谜题：解法必须从环境本身读出来，而不是从提示里读出来。

## 2. 声音需求

本阶段声音不需要大量制作，但必须形成明显的空间变化。

### 2.1 室外

风声、草木摩擦、远处环境声、低污染区域的自然环境声。

### 2.2 研究设施外围

在室外底噪之上加入：植物摩擦建筑的声音、换气扇低速运转声、金属结构轻微异响。

### 2.3 移开灰叶藤

藤蔓摩擦、植物被拉动的声音、金属结构轻响。

### 2.4 进入检修通道

立即降低自然环境声，并加入：空间混响、管道声、水滴、电机 / 风机低频声。

工程侧的 cue 与旗标对应关系见
[无线电与对话语音接入](../architecture/systems/无线电与对话语音接入.md) §5。

## 3. 验收标准

本阶段不以“模型是否精美”作为第一验收标准，而以玩家能否独立完成以下行为链条作为验收：

1. 玩家能够看到研究设施；
2. 玩家能够发现正门无法进入；
3. 玩家能够较早注意到“研究室入口 ↓”；
4. 玩家能够看到并调查灰叶藤；
5. 玩家能够从灰叶藤中发现细脉藤；
6. 玩家能够识别细脉藤；
7. 玩家能够将细脉藤信息与环境中的人工结构联系起来；
8. 玩家能够发现换气扇 / 管道方向；
9. 玩家能够定位被灰叶藤遮挡的区域；
10. 玩家能够主动触发“移开植物”；
11. 植物状态切换并显露检修入口；
12. 玩家能够进入检修通道。

判定方式：如果玩家需要策划人员口头告诉“去那里找入口”，则场景设计未通过；
如果玩家无需任何额外提示即可完成上述链条，则 00 章第一个环境谜题的基本设计成立。
