# 视觉效果索引

这里归档光点引导、区域生态变化、头盔 HUD、音频反馈和其他表现方案。

程序到表现层的接口边界见 [表现层驱动契约](../architecture/contracts/表现层驱动契约.md)。

- [低保真终端式 UI 规范](低保真终端式UI规范.md) — HUD/UI 的几何、配色、字体、VFX 与动效五阶段规范；复刻两块具体的屏（暖色标题卡、冷色数据屏）
- [电子类 UI 组件库规范](电子类UI组件库规范.md) — 可拼装的电子/仪器风 UI 组件库：主题、抖动着色器、一组预制件，以及组合成一屏而不失控的规则；与上一份文档目标不同、不共用渲染路径，两者可共存于同一项目
- [抖动着色器](抖动着色器.md) — 电子类 UI 组件库的图像呈现层：把任意灰度源图量化成硬边像素网点的 `Dither.shader`，参数含义与验证方法
