# Overriding prefab instance data

Use overrides to create variations of [prefab instances](https://docs.unity3d.com/6000.3/Documentation/Manual/CreatingPrefabs.html#create-an-instance-of-a-prefab), while still linking those instances to the same prefab asset.

|:---------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------|
| [Override prefab instances](https://docs.unity3d.com/6000.3/Documentation/Manual/PrefabInstanceOverrides.html) | Modify properties, components, or child GameObjects on individual prefab instances. |
| [Remove unused override data](https://docs.unity3d.com/6000.3/Documentation/Manual/UnusedOverrides.html)       | Clean up override data that’s no longer in use.                                     |
