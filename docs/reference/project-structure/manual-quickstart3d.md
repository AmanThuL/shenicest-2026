# Get started with 3D game development

**Tip:** If you have never used the Unity Editor before, start with the [First time users](https://docs.unity3d.com/6000.3/Documentation/Manual/first-time-user.html) documentation.

Everything in the Unity documentation, other than the 2D section, is relevant to 3D game development.

## Select platforms and render pipelines

The first two choices you must make are your 3D render pipeline and the platforms you want to support. These choices affect each other: some platforms don’t support the High Definition Render Pipeline (HDRP).

To get started, review the documentation for:

-   [Platforms](https://docs.unity3d.com/6000.3/Documentation/Manual/PlatformSpecific.html)
-   [Choosing a render pipeline](https://docs.unity3d.com/6000.3/Documentation/Manual/choose-a-render-pipeline-landing.html)

## Check third-party application compatibility

If you need to import assets from third-party applications, check that all applications can produce formats that Unity can import. For more information, refer to [Supported asset type reference](https://docs.unity3d.com/6000.3/Documentation/Manual/assets-supported-types.html).

## Create the game

What you focus on next depends on your role, but if you’re a sole creator, you might want to consider the following:

1.  Create an environment in your game:
    -   For a natural environment, use the [Terrain system](https://docs.unity3d.com/6000.3/Documentation/Manual/script-Terrain.html) or import an environment from a third-party modeling application.
    -   For a built environment, such as buildings and rooms, you can start with [placeholders](https://docs.unity3d.com/6000.3/Documentation/Manual/PrimitiveObjects.html) or import [models](https://docs.unity3d.com/6000.3/Documentation/Manual/models.html).
2.  Use [meshes](https://docs.unity3d.com/6000.3/Documentation/Manual/mesh.html) to place objects in the environment.
3.  Change [lights](https://docs.unity3d.com/6000.3/Documentation/Manual/LightingOverview.html) and [visual effects](https://docs.unity3d.com/6000.3/Documentation/Manual/visual-effects.html) to create the right mood for your game.
4.  [Animate](https://docs.unity3d.com/6000.3/Documentation/Manual/AnimationSection.html) characters and objects.
5.  Create user [input controls](https://docs.unity3d.com/6000.3/Documentation/Manual/Input.html) and user [interfaces](https://docs.unity3d.com/6000.3/Documentation/Manual/UIToolkits.html).
6.  Make your game [accessible](https://docs.unity3d.com/6000.3/Documentation/Manual/accessibility/_index.html) to reach a wider player base.
