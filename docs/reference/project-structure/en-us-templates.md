# Templates

Overview of the Unity Hub project templates and custom template window.

<span class="MuiTypography-root MuiTypography-caption mui-1vxjoe2" sentry-element="Typography" sentry-source-file="content-renderer.tsx">Read time 1 minute</span>

<span class="MuiTypography-root MuiTypography-caption mui-1vxjoe2">Last updated 25 days ago</span>

------------------------------------------------------------------------

A Template is a packaged version of a project that you can use as a starting point for a new project. The Templates window contains your custom templates. Use it to create a custom template based on your own project.

To access the Templates window, select the Templates tab in the left navigation menu.
