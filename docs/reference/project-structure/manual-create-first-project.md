# Create your first project

If you’re new to Unity, this page guides your through the steps to create your first project.

## Install the Unity Editor

1.  Check that your computer meets the [system requirements](https://docs.unity3d.com/6000.3/Documentation/Manual/system-requirements.html) for Unity.
2.  [Download and install the Unity Editor](https://unity.com/download). This process includes the following tasks:
    1.  Install the [Unity Hub](https://docs.unity3d.com/6000.3/Documentation/Manual/unity-hub.html), which manages your Unity installations and projects.
    2.  [Create a Unity account](https://login.unity.com/en/sign-in). Your account gives you access to free assets, collaboration tools, and other services that help you create games and interactive experiences.
    3.  Install the Unity Editor. Use version 6.1 or later.

## Create a project

Create a new Unity project in the Unity Hub:

1.  Open the Unity Hub.
2.  Select **Projects**.
3.  Select **New Project**
4.  Select a template.
5.  Name your project.
6.  Select **Create project**.

You can create a project from a template to learn about the Unity Engine. The Get Started with Unity template introduces you to core concepts and workflows. To learn more, refer to [Create a new project](https://docs.unity.com/en-us/hub/project-create).

If you’re not sure whether you want to make a 2D or 3D project, refer to [2D and 3D projects](https://docs.unity3d.com/6000.3/Documentation/Manual/2Dor3D.html).

**Important:** Using cloud-based storage methods to store your project is an unsupported workflow. It can cause synchronization issues which corrupt your project. Use [version control](https://docs.unity3d.com/6000.3/Documentation/Manual/VersionControl.html) to manage your project.

## Continue learning

To build your skills, complete the [Unity Essentials in-Editor Tutorials pathway](https://learn.unity.com/pathway/unity-essentials-in-editor?utm_source=first-time&utm_medium=docs). These tutorials teach 2D and 3D development fundamentals, such as programming, audio, cameras, and publishing.

As you use these resources, you can also:

-   Use the [Key concepts page](https://docs.unity3d.com/6000.3/Documentation/Manual/key-concepts.html) as reference to some Unity Editor concepts.
-   Browse topics you’re interested in, such as, such as [Input](https://docs.unity3d.com/6000.3/Documentation/Manual/Input.html), [Animation](https://docs.unity3d.com/6000.3/Documentation/Manual/AnimationSection.html), and [Lighting](https://docs.unity3d.com/6000.3/Documentation/Manual/LightingOverview.html).
