## Course Overview

If you’re new to software patterns or just need a refresher, this course will help you understand some of the most common software patterns you’ll encounter in Unity development.

Whether you need a factory pattern to spawn prefabs or a state pattern to control NPC AI behavior, follow these tutorials to learn more about programming patterns in Unity. Design patterns offer general solutions to common problems in software engineering. They aren’t ready-made templates to copy and paste into your code, but rather tools in your toolbox to draw upon when needed.

A design pattern can speed up your workflow and offer an elegant solution to a recurrent problem when applied correctly. Using them allows you to concentrate on what’s important: making a fun and unique experience for your players.

Every tutorial in this course is based on the updated guide <span class="unknown__pt__mark__425d2540-79a1-4b2a-aea2-f5ea3e20d658">Level up your code with design patterns and SOLID</span> (Unity 6 edition) and references the <span class="unknown__pt__mark__d8598b65-2a5c-4341-ac75-7ea89ec8bd3c">Level up your code with design patterns and SOLID</span> sample project from the Unity Asset Store.

Make sure you <span class="unknown__pt__mark__07d85fac-6c0e-4977-a48e-f1e81a693e63">download the sample project</span> so that you can follow along with the examples.

Some of the tutorials in this project will only work with Unity 6. If you’re using Unity 2022.3 or below, please check out the <span class="unknown__pt__mark__a7488a58-537f-42de-b19a-7ba439ac0be6">Design Patterns</span> project for tutorials that can be used with your specific version of Unity.
