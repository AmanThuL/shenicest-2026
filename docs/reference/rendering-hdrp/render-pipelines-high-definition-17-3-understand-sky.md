# Understand sky

You can create the following types of sky if your project use the High Definition Render Pipeline (HDRP):

- [Physically based sky](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.3/manual/create-a-physically-based-sky.html)
- [High dynamic range imaging (HDRI) sky](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.3/manual/create-an-hdri-sky.html), which is a simple sky that uses a cubemap texture.
- [Gradient sky](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.3/manual/create-a-gradient-sky.html), which is a simple sky where HDRP interpolates between three colors.
- [Custom sky effects](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.3/manual/create-a-custom-sky.html)

Use a [Visual Environment Volume Override](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.3/manual/visual-environment-volume-override-reference.html) to change the type of sky HDRP uses, and configure the sky and clouds.
