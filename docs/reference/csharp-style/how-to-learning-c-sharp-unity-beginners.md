## Pathway Description

Welcome to Junior Programmer! Designed for anyone interested in learning to code or obtaining an entry-level Unity role, this pathway assumes a basic knowledge of Unity and has no math prerequisites. Junior Programmer prepares you to get Unity Certified so that you can demonstrate your job-readiness to employers.

### Prerequisites

We recommend that you have basic knowledge of Unity or complete <a href="https://learn.unity.com/pathway/unity-essentials" class="link-primary text-inherit">Unity Essentials</a> before starting this pathway.

### Skills you will learn

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 1 Version control</span></span><span class="Accordion_icon__gERbi"></span>

-   Maintain a project by correctly implementing version control

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 1 Debugging</span></span><span class="Accordion_icon__gERbi"></span>

-   Diagnose and fix code that compiles, but fails to perform as expected

-   Diagnose and fix common compilation errors

-   Diagnose and fix compilation errors related to Unity’s Scripting API

-   Diagnose and fix the cause of an exception

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 1 Project Management</span></span><span class="Accordion_icon__gERbi"></span>

-   Plan projects in the real-time development cycle

-   Manage projects in the real-time development cycle

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 1 Code Comprehension</span></span><span class="Accordion_icon__gERbi"></span>

-   Interpret basic code in a Unity code base

-   Improve simple code using the features of an IDE

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 1 Job Preparation</span></span><span class="Accordion_icon__gERbi"></span>

-   Prepare yourself for the job search

-   Create a portfolio, enabling you to pursue a job in real-time development

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Programming User Interfaces</span></span><span class="Accordion_icon__gERbi"></span>

-   Create user interfaces as defined in design documents.

-   Write scripts for interactive user interfaces.

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 1 Code optimization</span></span><span class="Accordion_icon__gERbi"></span>

-   Maximize code efficiency by correctly executing coding best practices

-   Debug performance issues

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 1 Design process</span></span><span class="Accordion_icon__gERbi"></span>

-   Implement an iterative design process

-   Coordinate a user feedback and testing session

-   Practice putting the user first

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 1 Application Scripting</span></span><span class="Accordion_icon__gERbi"></span>

-   Control the execution of code with common logic structures

-   Compose scripts that utilize various APIs

-   Implement appropriate data types

-   Write code that integrates into an existing system

-   Cultivate a code style that is efficient and easy to read

-   Prototype new concepts

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Communication & Collaboration</span></span><span class="Accordion_icon__gERbi"></span>

-   Participating in listening, constructive feedback cycles, and peer review

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 2 Application scripting</span></span><span class="Accordion_icon__gERbi"></span>

-   Create the scene flow in an application state

-   Implement data persistence across scenes and user sessions

<span class="Accordion_accordionToggleContent__5r31e"><span class="headingXS text-left text-white">Level 2 Programming theory</span></span><span class="Accordion_icon__gERbi"></span>

-   Simplify code and make it reusable by correctly implementing the principles of inheritance and polymorphism

-   Make code more secure and usable by correctly implementing the principles of abstraction and encapsulation, including the use of interfaces

-   Write efficient, organized, and comprehensible code by correctly implementing the principles of object-oriented programming
