# Optimize mesh rendering using level of detail (LOD)

Strategies and resources for applying level of detail (LOD) techniques to meshes to reduce rendering workload.

This section contains information on LOD techniques for meshes. For information on LOD techniques for shaders, refer to [SubShader LOD value](https://docs.unity3d.com/6000.3/Documentation/Manual/SL-ShaderLOD.html).

| **Topic**                                                                                                          | **Description**                                                                                                                                                                                                                                              |
|:-------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [Introduction to level of detail](https://docs.unity3d.com/6000.3/Documentation/Manual/LevelOfDetail.html)         | Understand level of detail (LOD) and LOD indices, and learn about the LOD features available in Unity.                                                                                                                                                       |
| [Mesh LOD](https://docs.unity3d.com/6000.3/Documentation/Manual/lod/mesh-lod-landing.html)                         | Mesh LOD is a Unity feature that reduces the number of polygons to draw with minimum memory footprint and computational overhead.                                                                                                                            |
| [LOD Group](https://docs.unity3d.com/6000.3/Documentation/Manual/lod/lod-group-landing.html)                       | LOD Group is a flexible Unity LOD solution. It provides more optimization options than the [Mesh LOD](https://docs.unity3d.com/6000.3/Documentation/Manual/lod/mesh-lod-landing.html) feature, but has a larger memory footprint and computational overhead. |
| [2D images for low level of detail (LOD)](https://docs.unity3d.com/6000.3/Documentation/Manual/2d-images-lod.html) | Techniques and resources for using 2D billboards to simplify 3D meshes that are far away.                                                                                                                                                                    |
