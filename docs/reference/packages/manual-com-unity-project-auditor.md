# Project Auditor

<span class="notooltips"></span>

[com.unity.project-auditor](https://docs.unity3d.com/Packages/com.unity.project-auditor@3.0/manual/index.html) ![](https://docs.unity3d.com/6000.3/Documentation/uploads/Main/iconRel.png)

## Description

Project Auditor is a static analysis tool that analyzes assets, settings, and scripts of the Unity project and produces a report containing: Code and Settings Diagnostics, the last BuildReport, and assets information.
