# Unity's Timeline

Use Unity's Timeline to create cinematic content, gameplay sequences, audio sequences, and complex particle effects.

Each cut-scene, cinematic, or gameplay sequence that you create with Unity's Timeline consists of a Timeline asset and a Timeline instance. The [Timeline window](https://docs.unity3d.com/Packages/com.unity.timeline@1.8/manual/tl-window.html) creates and modifies Timeline assets and Timeline instances simultaneously.

The [Timeline assets and instances topic](https://docs.unity3d.com/Packages/com.unity.timeline@1.8/manual/tl-overview.html) provides details on the relationship between the Timeline window, Timeline assets, and Timeline instances.

The [Timeline Workflows section](https://docs.unity3d.com/Packages/com.unity.timeline@1.8/manual/wf-overview.html) provides basic steps on how to create Timeline assets and Timeline instances, record basic animation, animate humanoids, use Animation Override tracks, Sub-Timelines, and other Timeline features.

The [Timeline Samples section](https://docs.unity3d.com/Packages/com.unity.timeline@1.8/manual/samp-overview.html) provides a description of the samples included in the Timeline package.
