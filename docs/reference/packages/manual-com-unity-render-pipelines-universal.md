# Universal Render Pipeline

<span class="notooltips"></span>

[com.unity.render-pipelines.universal](https://docs.unity3d.com/Packages/com.unity.render-pipelines.universal@17.3/manual/index.html)

## Description

The Universal Render Pipeline (URP) is a prebuilt Scriptable Render Pipeline, made by Unity. URP provides artist-friendly workflows that let you quickly and easily create optimized graphics across a range of platforms, from mobile to high-end consoles and PCs.

## Version information

Core packages are fixed to a single version matching the Editor version.
