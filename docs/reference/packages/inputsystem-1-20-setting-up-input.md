# Setting up input

Configure how your project maps physical controls to gameplay and UI behavior.

Use actions, action assets, and the Input Actions Editor to define what input means in your game, then wire bindings, interactions, and processors. When you are ready to read input in code, continue to [Respond to input](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/respond-to-input.html).

| **Topic**                                                                                                                                   | **Description**                                                                   |
|:--------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------|
| **[Actions](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/Actions.html)**                                             | Separate input purpose from device controls and connect them with bindings.       |
| **[Input action assets](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/action-assets.html)**                           | Store actions, bindings, action maps, and control schemes in Input action assets. |
| **[Create action maps](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/create-edit-delete-action-maps.html)**           | Group actions for different input scenarios such as gameplay and UI.              |
| **[Create, edit, and delete actions](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/create-edit-delete-actions.html)** | Create and manage actions in the Input Actions Editor.                            |
| **[Configure actions](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/configure-actions.html)**                         | Set up action types, bindings, controls, schemes, interactions, and processors.   |
| **[Input Actions Editor references](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/actions-editor.html)**              | Reference for the Actions Editor window and property panels.                      |
| **[Configure input from code](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/configure-input-from-code.html)**         | Define actions, bindings, and maps in script without relying on asset-only setup. |
