# Visual Studio Editor

<span class="notooltips"></span>

[com.unity.ide.visualstudio](https://docs.unity3d.com/Packages/com.unity.ide.visualstudio@2.0/manual/index.html) ![](https://docs.unity3d.com/6000.3/Documentation/uploads/Main/iconRel.png)

## Description

Code editor integration for supporting Visual Studio as code editor for unity. Adds support for generating csproj files for intellisense purposes, auto discovery of installations, etc.

## Version information

### Released for Unity
