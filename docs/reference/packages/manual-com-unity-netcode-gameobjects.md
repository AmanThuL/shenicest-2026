# Netcode for GameObjects

<span class="notooltips"></span>

[com.unity.netcode.gameobjects](https://docs.unity3d.com/Packages/com.unity.netcode.gameobjects@2.13/manual/index.html) ![](https://docs.unity3d.com/6000.3/Documentation/uploads/Main/iconRel.png)

## Description

Netcode for GameObjects is a high-level netcode SDK that provides networking capabilities to GameObject/MonoBehaviour workflows within Unity and sits on top of underlying transport layer.
