# Unity UI (uGUI)

Unity UI (uGUI) is a GameObject-based UI system that you can use to develop user interfaces for games and applications. It uses Components and the Game view to arrange, position, and style user interfaces.

| Topic                                                                                                                       | Description                                                                                                                   |
|:----------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------|
| [Canvas](https://docs.unity3d.com/Packages/com.unity.ugui@2.0/manual/UICanvas.html)                                         | The Canvas is an area where you can place UI elements.                                                                        |
| [Basic Layout](https://docs.unity3d.com/Packages/com.unity.ugui@2.0/manual/UIBasicLayout.html)                              | Position elements like text and images on a canvas.                                                                           |

| [Interaction Components](https://docs.unity3d.com/Packages/com.unity.ugui@2.0/manual/UIInteractionComponents.html)          | Set up user interactions with elements on a canvas.                                                                           |

| [Auto Layout](https://docs.unity3d.com/Packages/com.unity.ugui@2.0/manual/UIAutoLayout.html)                                | Change the size of layouts automatically.                                                                                     |

##### Note

You can't use uGUI to create or change user interfaces of the Unity Editor.
