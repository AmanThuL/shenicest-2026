# Input settings

The Input settings panel, available in the Project Settings window, allows you to configure various features and behaviors of the Input System. This section explains how to create a settings asset, and the options available in all settings.

| **Topic**                                                                                                                             | **Description**                                                        |
|:--------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------|
| **[Create a settings asset](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/create-settings-asset.html)**         | Create a settings asset to change input settings in your project.      |
| **[Update Mode](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/update-mode.html)**                               | Set when to process input.                                             |
| **[Background behavior](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/background-behavior.html)**               | Decide how to behave when the application's focus is lost or regained. |
| **[Compensate orientation](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/compensate-orientation.html)**         | Set rotation values around the Z axis.                                 |
| **[Default value properties](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/default-value-properties.html)**     | Set default values for numerical properties.                           |
| **[Supported devices](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/supported-devices.html)**                   | Restrict input devices to those your project needs.                    |
| **[Platform-specific settings](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/platform-specific-settings.html)** | Select options for individual platforms.                               |
