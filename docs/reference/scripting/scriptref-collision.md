### Description

Describes a collision.

Collision information is passed to [Collider.OnCollisionEnter](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Collider.OnCollisionEnter.html), [Collider.OnCollisionStay](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Collider.OnCollisionStay.html) and [Collider.OnCollisionExit](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Collider.OnCollisionExit.html) events.  
  
**Note**: The contact points are in world-space.  
  
Additional resources: [ContactPoint](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/ContactPoint.html).
