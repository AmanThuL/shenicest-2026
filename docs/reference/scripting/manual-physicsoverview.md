# Built-in 3D physics

Unity’s default built-in 3D physics system is an integration of the Nvidia PhysX engine. You can use this system in object-oriented 3D projects.

This section includes the following topics.

| **Topic**                                                                                                                 | **Description**                                                                                                           |
|:--------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| **[Character control](https://docs.unity3d.com/6000.3/Documentation/Manual/character-control-section.html)**              | Configure physics-based character control for first-person and third-person characters.                                   |
| **[Rigidbody physics](https://docs.unity3d.com/6000.3/Documentation/Manual/rigidbody-physics-section.html)**              | Apply physics-based behavior to GameObjects.                                                                              |
| **[Collision](https://docs.unity3d.com/6000.3/Documentation/Manual/collision-section.html)**                              | Use colliders to configure collisions between GameObjects.                                                                |
| **[Joints](https://docs.unity3d.com/6000.3/Documentation/Manual/joints-section.html)**                                    | Apply and configure joints that connect GameObjects and simulate physical forces for pivoting, movement, and restriction. |
| **[Articulations](https://docs.unity3d.com/6000.3/Documentation/Manual/articulations-section.html)**                      | Configure complex systems of rigid bodies and joints.                                                                     |
| **[Ragdoll physics](https://docs.unity3d.com/6000.3/Documentation/Manual/ragdoll-physics-section.html)**                  | Configure ragdoll physics for characters.                                                                                 |
| **[Optimize physics performance](https://docs.unity3d.com/6000.3/Documentation/Manual/physics-optimization.html)**        | Optimize physics system performance in the Unity Editor.                                                                  |
| **[Cloth](https://docs.unity3d.com/6000.3/Documentation/Manual/class-Cloth.html)**                                        | Simulate fabric movement for character clothing and other in-application textiles.                                        |
| **[Multi-scene physics](https://docs.unity3d.com/6000.3/Documentation/Manual/physics-multi-scene.html)**                  | Manage different physics contexts in one project with multiple dedicated physics scenes.                                  |
| **[Physics Debug window reference](https://docs.unity3d.com/6000.3/Documentation/Manual/PhysicsDebugVisualization.html)** | Use the Physics Debug window to configure and generate visual representations of 3D physics activity in a scene.          |
| **[Physics Profiler module](https://docs.unity3d.com/6000.3/Documentation/Manual/ProfilerPhysics.html)**                  | Analyze the performance of physics in your application.                                                                   |
