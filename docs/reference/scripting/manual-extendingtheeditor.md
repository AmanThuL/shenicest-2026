# Extending the Editor with IMGUI

**Note**: It’s strongly recommended to use the [UI Toolkit](https://docs.unity3d.com/6000.3/Documentation/Manual/UIElements.html) to extend the [Unity Editor](https://docs.unity3d.com/6000.3/Documentation/Manual/UIE-support-for-editor-ui.html), as it provides a more modern, flexible, and scalable solution than IMGUI.

Unity lets you extend the editor with your own custom inspectors and **Editor Windows** and you can define how properties are displayed in the inspector with custom **Property Drawers**. This section explains how to use these features.

| Topic                                                                                                                                          | Description                                                     |
|:-----------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------|
| [Create custom Editor Windows with IMGUI](https://docs.unity3d.com/6000.3/Documentation/Manual/editor-EditorWindows.html)                      | Create custom windows in your app.                              |
| [Create custom Editors with IMGUI](https://docs.unity3d.com/6000.3/Documentation/Manual/editor-CustomEditors.html)                             | Create custom editors for components you commonly use.          |
| [Use Property Drawers with IMGUI to customize the Inspector](https://docs.unity3d.com/6000.3/Documentation/Manual/editor-PropertyDrawers.html) | Customize the look of certain controls in the Inspector window. |
| [Create TreeView with IMGUI](https://docs.unity3d.com/6000.3/Documentation/Manual/TreeViewAPI.html)                                            | Create custom tree views in the Editor.                         |
