<span style="color:red;"> </span>public static bool <span class="sig-kw">enterPlayModeOptionsEnabled</span>;

### Description

Determines whether the Enter Play Mode Options are enabled in the Unity Editor or not.

This feature helps reduce Editor iteration time by allowing you to disable Domain Reload and Scene Reload from the Enter Play Mode process by changing the [EditorSettings.enterPlayModeOptions](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/EditorSettings-enterPlayModeOptions.html) Editor Settings.
