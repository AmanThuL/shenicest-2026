# Writing tests

Use the Unity Test Framework APIs to write tests specially adapted to the unique features of the Unity Editor and runtime.

| **Topic**                                                                                                                                             | **Description**                                                                                                                                |

| **[Performing actions before and after tests](https://docs.unity3d.com/6000.3/Documentation/Manual/test-framework/before-and-after-tests.html)**      | Perform pre-test setup and post-test cleanup to ensure your tests run in the right conditions.                                                 |
| **[Asserting and comparing](https://docs.unity3d.com/6000.3/Documentation/Manual/test-framework/asserting-and-comparing.html)**                       | Perform assertions with constraints and compare the values of custom Unity types in your tests.                                                |
| **[Yield instructions for the Editor](https://docs.unity3d.com/6000.3/Documentation/Manual/test-framework/reference-custom-yield-instructions.html)** | Yield instructions for the Unity Editor from your Edit mode tests, using either a set of pre-defined common instructions or defining your own. |
| **[Writing parameterized tests](https://docs.unity3d.com/6000.3/Documentation/Manual/test-framework/reference-tests-parameterized.html)**             | Write parameterized tests for data-driven testing.                                                                                             |
