# Command-line interface

You can run the Unity Editor and Players from command-line interfaces to change and customize how they run at launch time.

| **[Run Unity from a command-line interface](https://docs.unity3d.com/6000.3/Documentation/Manual/command-line-run-unity.html)**            | Understand how to launch Unity from the command line and execute scripts.                            |
| **[Unity Editor command-line arguments reference](https://docs.unity3d.com/6000.3/Documentation/Manual/EditorCommandLineArguments.html)**  | A list of arguments you can use when you launch a version of the Unity Editor from the command line. |
