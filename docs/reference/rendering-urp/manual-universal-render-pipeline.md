# Using the Universal Render Pipeline

![Universal Render Pipeline cross-platform rendering example.](https://docs.unity3d.com/6000.3/Documentation/uploads/Main/urp-example.png)

The Universal Render Pipeline (URP) is a prebuilt [Scriptable Render Pipeline](https://docs.unity3d.com/6000.3/Documentation/Manual/scriptable-render-pipeline-introduction.html), made by Unity. URP provides artist-friendly workflows that let you quickly and easily create optimized graphics across a range of platforms, from mobile to high-end consoles and PCs.
