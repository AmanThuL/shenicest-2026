# Custom post-processing in URP

The Universal Render Pipeline (URP) provides a variety of pre-built [post-processing effects](https://docs.unity3d.com/6000.3/Documentation/Manual/urp/integration-with-post-processing.html) that you can adjust to create a particular visual effect or style. URP also lets you create custom post-processing effects.

The following page describe different approaches to creating custom post-processing effects.

| [Create a custom post-processing effect with Volume support](https://docs.unity3d.com/6000.3/Documentation/Manual/urp/post-processing/custom-post-processing-with-volume.html) | How to create a custom post-processing effect with Volume support.                       |
