# Rendering Debugger in URP

The Rendering Debugger lets you visualize various lighting, rendering, and Material properties. The visualizations help you identify rendering issues and optimize scenes and rendering configurations.

| Page                                                                                                                                             | Description                                                                                                                                         |
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| [Enable the Rendering Debugger](https://docs.unity3d.com/6000.3/Documentation/Manual/urp/features/rendering-debugger-use.html)                   | Open the Rendering Debugger as a window in the Editor, or as an overlay in Game view, Play Mode, or your built application.                         |
| [Add controls to the Rendering Debugger](https://docs.unity3d.com/6000.3/Documentation/Manual/urp/features/rendering-debugger-add-controls.html) | Customise the Rendering Debugger window with your own controls and scripts, to visualize your project’s lighting, rendering or material properties. |
