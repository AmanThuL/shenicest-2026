# Injection points reference for URP

URP contains multiple injection points that let you inject render passes into the frame rendering loop and execute them upon different events.

Injection points give a custom render pass access to URP buffers. A render pass has read and write access to all buffers at each injection point.

Unity provides the following events in the rendering loop. You can use these events to inject your custom passes.

<table><thead><tr class="header"><th style="text-align: left;"><strong>Injection point</strong></th><th style="text-align: left;"><strong>Description</strong></th></tr></thead><tbody><tr class="odd"><td style="text-align: left;">BeforeRendering</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance before rendering any other passes in the pipeline for the current Camera. Camera matrices and stereo rendering are not set up at this point. You can use this injection point to draw to custom input textures used later in the pipeline, for example, LUT textures.</td></tr><tr class="even"><td style="text-align: left;">BeforeRenderingShadows</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance before rendering shadow maps (<strong>MainLightShadow</strong>, <strong>AdditionalLightsShadow</strong> passes).<br />
Camera matrices and stereo rendering are not set up at this point.</td></tr><tr class="odd"><td style="text-align: left;">AfterRenderingShadows</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance after rendering shadow maps (<strong>MainLightShadow</strong>, <strong>AdditionalLightsShadow</strong> passes).<br />
Camera matrices and stereo rendering are not set up this point.</td></tr><tr class="even"><td style="text-align: left;">BeforeRenderingPrePasses</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance before rendering prepasses (<strong>DepthPrepass</strong>, <strong>DepthNormalPrepass</strong> passes).<br />
Camera matrices and stereo rendering are already set up at this point.</td></tr><tr class="odd"><td style="text-align: left;">AfterRenderingPrePasses</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance after rendering prepasses (<strong>DepthPrepass</strong>, <strong>DepthNormalPrepass</strong> passes).<br />
Camera matrices and stereo rendering are set up at this point.</td></tr><tr class="even"><td style="text-align: left;">BeforeRenderingGbuffer</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance before rendering the <strong>GBuffer</strong> pass.</td></tr><tr class="odd"><td style="text-align: left;">AfterRenderingGbuffer</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance after rendering the <strong>GBuffer</strong> pass.</td></tr><tr class="even"><td style="text-align: left;">BeforeRenderingDeferredLights</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance before rendering the <strong>Deferred</strong> pass.</td></tr><tr class="odd"><td style="text-align: left;">AfterRenderingDeferredLights</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance after rendering the <strong>Deferred</strong> pass.</td></tr><tr class="even"><td style="text-align: left;">BeforeRenderingOpaques</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance before rendering opaque objects (<strong>DrawOpaqueObjects</strong> pass).</td></tr><tr class="odd"><td style="text-align: left;">AfterRenderingOpaques</td><td style="text-align: left;">Executes a pass).</td></tr><tr class="odd"><td style="text-align: left;">AfterRenderingSkybox</td><td style="text-align: left;">Executes a <code>ScriptableRenderPass</code> instance after rendering the skybox
