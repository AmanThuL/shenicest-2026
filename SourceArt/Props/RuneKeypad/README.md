# Rune Keypad

Editable source and license record for the rune keypad prop.

## Game Credit

Keypad Codelock Free Game Ready Asset by AMMediaGames, modified for

- Source: https://sketchfab.com/3d-models/keypad-codelock-free-game-ready-asset-77b01f5f09694d5bbbf3f21e16310216
- License: https://creativecommons.org/licenses/by/4.0/

The project modification replaces the numeric keypad with original rune-like
symbols, adds delete and confirm controls, and adds a recessed green display.

This attribution must appear in the shipped game's credits.
